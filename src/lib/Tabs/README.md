# Tabs

Вкладки. Позволяют разложить много компонентов на несколько страниц в одном месте.

## Назначение

Несколько страниц компонентов в одном месте.

## Пакет данных

С устройством не связаны.

## Особенности

- У каждой вкладки своя сетка. В конструкторе компоненты кладут на активную вкладку.
- Вкладок не больше десяти.
- Рисуется только содержимое выбранной вкладки.
- Выбранная вкладка отмечается линией акцентного цвета.
- Положение иконки относительно текста задаёт класс вкладки: `flex-row`, `flex-col`, `flex-row-reverse`, `flex-col-reverse`. Класс `flex-1` растягивает вкладки поровну.
- В конструкторе у каждой вкладки есть постоянный `id`. По нему содержимое переезжает вместе с вкладкой, когда вкладки переставляют или удаляют.

Содержимое можно передать тремя способами:

1. общий сниппет `children`, он получает текущую вкладку;
2. сниппет у каждой вкладки `items[].children`;
3. список компонентов `apiArray` и сниппет `Components`, который их рисует. Так делают конструктор и превью интерфейса.

## Пропсы

| Название | Тип | По умолчанию | Описание |
|---|---|---|---|
| `id` | `string` | `crypto.randomUUID()` | Идентификатор |
| `items` | `ITabItem[]` | две вкладки | Вкладки |
| `items[].id` | `string` | | Постоянный id вкладки |
| `items[].name` | `string` | | Подпись |
| `items[].icon` | `Component \| string` | | Иконка |
| `items[].class` | `string` | | Классы вкладки |
| `items[].children` | `Snippet` | | Содержимое вкладки |
| `items[].onClick` | `() => void` | | Нажатие на вкладку |
| `items[].disabled` | `boolean` | | Вкладка неактивна |
| `activeTab` | `number` | `0` | Номер выбранной вкладки. Можно связать через `bind:activeTab` |
| `wrapperClass` | `string` | `""` | Классы полосы вкладок, например `justify-center` |
| `size` | `{ width, height }` | `12 × 6` | Сетка содержимого: колонки и строки |
| `children` | `Snippet<[item]>` | | Общее содержимое |
| `apiArray` | `UIComponent[]` | `[]` | Компоненты для `Components` |
| `Components` | `Snippet<[component, fixedHeight]>` | | Как рисовать компонент из `apiArray` |

## Пример

```svelte
<script>
  import * as UI from "poe-svelte-ui-lib"
  let tab = $state(0)
</script>

<UI.Tabs items={[{ name: "Сеть" }, { name: "Система" }]} bind:activeTab={tab}>
  {#snippet children(item)}
    <p>{item.name}</p>
  {/snippet}
</UI.Tabs>
```

## Панель свойств (TabsProps.svelte)

В конструкторе добавляют, переставляют и удаляют вкладки, задают им подписи и иконки, ширину («Равные» или «Авто») и размер сетки.
