# Graph

График нескольких значений во времени. Каждое новое значение добавляет точку справа, старые уезжают влево.

## Назначение

Линии значений, обновляющиеся в реальном времени.

## Пакет данных

- Читает одну переменную. Каждое обновление добавляет точку.
- Частые данные лучше слать потоком телеметрии устройства (`Telemetry_SendGraph` в `stream_client`), а не командным каналом.
- Только показывает, ничего не отправляет.

## Ключи

| Ключ | Описание |
|---|---|
| `<переменная>` | Массив `[{ "name": "Temp", "value": 23.4 }, ...]`. Каждое `name` это своя линия, `value` число |

## Особенности

- Линий не больше шести, лишние не рисуются.
- Справа от графика легенда: цвет, имя и текущее значение каждой линии. Длинное имя обрезается, полное видно в подсказке.
- Для накопленных значений по периодам (энергия за час или сутки) удобнее `PeriodChart`.
- Рисуется на canvas и подстраивается под размер контейнера. В сетке и во flex график не распирает колонку.
- Старые точки удаляются, память не растёт.

### Два режима

**Живой.** Данные приходят в `streamingData.data`. Когда рисовать новую точку, решает `refreshRate`:

- `0` (AUTO) - точка добавляется, когда значения действительно изменились;
- число - точка добавляется раз в столько миллисекунд.

**Статический.** Если передан непустой `historyData`, график рисует готовый ряд с отметками времени, например энергию за сутки по часам. Точки сортируются по времени сами. Новый массив `historyData` перерисовывает график целиком.

`isTest` включает режим имитации: случайные данные, точка каждые 50 мс. Удобно, чтобы посмотреть график без устройства. Пока режим включён, данные устройства и `refreshRate` не учитываются. В конструкторе все остальные свойства становятся бледными и недоступными, пока имитацию не выключат.

## Пропсы

| Название | Тип | По умолчанию | Описание |
|---|---|---|---|
| `id` | `string` | `crypto.randomUUID()` | Идентификатор |
| `wrapperClass` | `string` | `""` | Классы обёртки |
| `label.name`, `label.class` | `string` | `""` | Заголовок и его классы |
| `streamingData.data` | `{ name, value }[] \| null` | `[]` | Текущие значения линий для живого режима |
| `refreshRate` | `number` | `0` | Период добавления точек, мс. `0` - по изменению значений |
| `historyData` | `{ name, points: { value, timestamp }[] }[]` | `[]` | Готовый ряд для статического режима. `timestamp` в миллисекундах, как `Date.now()` |
| `isTest` | `boolean` | `false` | Режим имитации: случайные данные, точка каждые 50 мс |

Колбэков нет.

## Примеры

```svelte
<script>
  import * as UI from "poe-svelte-ui-lib"
  let values = $state([{ name: "Temp", value: 23.4 }, { name: "Hum", value: 41 }])
</script>

<UI.Graph label={{ name: "Климат" }} streamingData={{ data: values }} />

<UI.Graph
  label={{ name: "Энергия за сутки" }}
  historyData={[{ name: "kWh", points: [{ timestamp: 1767225600000, value: 1.2 }, { timestamp: 1767229200000, value: 0.9 }] }]}
/>
```

## Панель свойств (GraphProps.svelte)

В конструкторе выбирают переменную, период обновления `refreshRate` и включают тестовые данные.
