# 🧲 WidgetMag

Показания магнитометра и его калибровка. Поле по осям, его модуль и качество калибровки видны крупными надписями. Виджет подходит к любому магнитометру, у которого в прошивке тот же договор ключей.

## ✨ Что умеет

- 🧭 Показывает магнитное поле по осям и его модуль. У Земли он 25-65 мкТл.
- 📊 Показывает качество последней калибровки цветом: зелёный - хорошо, оранжевый - так себе, красный - пора калибровать.
- 🚦 Показывает режим датчика: стоп, измеряет, калибровка или по запросу.
- 🎯 Кнопкой «Калибровать» запускает калибровку и подсказывает, что делать с устройством.
- ⏳ Пока идёт калибровка, показывает полосу времени, а потом сам перечитывает настройки датчика.
- 🔽 Сворачивается по клику на заголовок.
- ❓ Кнопка «?» в шапке включает подсказки.

## 🧩 Как настроить в конструкторе

1. Перетащите виджет на макет. Привязывать переменные не нужно.
2. Если нужно, задайте заголовок. Без него карточка называется «Магнитометр» на языке пользователя.
3. Если в прошивке у магнитометра другая группа настроек, впишите её. По умолчанию это `MAGF`.
4. Выберите мастер-цвет виджета.

## 💡 Полезно знать

- 🔄 Во время калибровки устройство медленно вращают во все стороны, до 30 секунд.
- 🧱 Модуль поля сильно больше 65 мкТл - рядом железо или магнит, и курс по магнитометру будет врать.
- 🔁 После калибровки датчик сам снова начинает измерять.
- ⚙️ Настройки самого чипа (частота, число циклов, оси) виджет не трогает. Их ставят обычными полями рядом.
- 📐 Виджет занимает всю ширину своей ячейки, а высота подстраивается под содержимое.

<details>
<summary>📦 Договор с прошивкой</summary>

- Работает с полями группы `MAGF`. Группу можно сменить префиксом в настройках.
- Режим датчика - биты 0-1 слова `Cfg`: `0` стоп, `1` измерять, `2` калибровать, `3` по запросу. Так у драйвера RM3100 и должно быть у любого другого драйвера магнитометра.
- «Калибровать» отправляет `SET ModuleConfig {MAGF.Cfg: слово}`, где в битах 0-1 стоит `2`, а остальные биты как были.
- Прошивка сама возвращается в измерение, но `Cfg` и `CQ` без запроса не присылает. Поэтому через `calibrateMs` (по умолчанию 30000 мс) виджет зовёт `onRefresh`, и приложение шлёт `GET ModuleConfig {CfgGroup: MAGF}`.
- Показания только читаются. Обычно они приходят потоком `OK! SystemDataStream`.

</details>

<details>
<summary>🔑 Ключи</summary>

| Ключ             | Описание                                          |
| ---------------- | ------------------------------------------------- |
| `Cfg`            | Биты 0-1 - режим, остальные биты - настройки чипа |
| `CX`, `CY`, `CZ` | Магнитное поле, мкТл                              |
| `CQ`             | Качество калибровки, 0-100%                       |

</details>
