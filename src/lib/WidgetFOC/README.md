# 🌀 WidgetFOC

Мотор с векторным управлением (FOC): включён ли он, где вал, какой ток, и все настройки мотора и регуляторов в одном месте. Отсюда же включают мотор, калибруют ноль и запускают автонастройку.

## ✨ Что умеет

- 🚦 Показывает, включён ли мотор, и флаги оси: ноль известен, выход в угол, калибровка нуля, занят процедурой, поток уставок прервался.
- 📐 Показывает угол вала, °, скорость, °/с, ток момента Iq, А, и напряжение Uq, В. Пока виджет раскрыт, данные обновляются раз в секунду.
- 🔌 Кнопка «Включить» или «Выключить» мотор.
- 🧲 «Калибровка нуля» находит ноль и направление мотора, «Автонастройка» подбирает регуляторы на выбранную полосу. Обе спрашивают подтверждение - вал будет двигаться.
- ⚙️ Разделы настроек: мотор, пределы и режимы, контуры тока, скорости и угла, датчик тока и фильтры. Изменения сохраняются кнопкой «Сохранить», «Заводские» возвращают заводские настройки.
- 📏 Всё в градусах: угол, °, скорость, °/с, коэффициенты регулятора скорости - на °/с.
- 🔽 Сворачивается по клику на заголовок.
- ❓ Кнопка «?» в шапке включает подсказки.

## 🧩 Как настроить в конструкторе

1. Перетащите «Мотор FOC» на холст.
2. В свойствах при необходимости смените группу (по умолчанию `FOC`).
3. Переменные привязывать не нужно: виджет сам берёт поля группы.

## 💡 Полезно знать

- 🔒 Пока идёт калибровка нуля или процедура устройства, кнопки и настройки недоступны.
- 🧭 Направление и ноль мотора меняет только калибровка нуля, нули датчика тока мотор меряет сам при включении - эти поля только для чтения.
- 📐 Виджет занимает всю ширину своей ячейки, а высота подстраивается под содержимое.

<details>
<summary>🔧 Для программиста</summary>

- Работает с полями группы `FOC` компонента `foc_control` прошивки. Группу можно сменить префиксом в настройках.
- Пока виджет раскрыт, раз в `refreshMs` (по умолчанию 1000 мс, 0 - не перечитывать) он зовёт `onRefresh`: облако и терминал шлют `GET ModuleConfig {CfgGroup: FOC}`, в ответе и настройки, и состояние оси.
- `onEnable(on)` - `SET MotionEnable {On}`, `onZero` - `SET MotionCalibrate {}`, `onTune(hz)` - `SET ModuleConfig {TuneHz: hz, Run: 1}`, `onSave(values)` - `SET ModuleConfig` только с изменёнными полями, `onDefaults` - `SET SystemDefaultConfig {CfgGroup}`.

| Ключ                                   | Что это                                                                                                                               |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `Ang`, `Vel`                           | Угол вала, 0-360°, и скорость, °/с; только чтение                                                                                     |
| `Iq`, `Uq`                             | Ток момента, А, и напряжение по оси q, В; только чтение                                                                               |
| `Flg`                                  | Флаги: 0x01 включён, 0x02 выход в угол, 0x04 калибровка нуля, 0x08 поток уставок прервался, 0x10 ноль известен, 0x20 занят процедурой |
| `M_Type`, `M_PP`, `M_R`, `M_L`, `M_KV` | Тип мотора (0 BLDC, 1 шаговый), пары полюсов, R, Ом, L, Гн, KV                                                                        |
| `M_Dir`, `ZEA`                         | Направление и ноль мотора, электрические °; только чтение                                                                             |
| `M_VL`, `M_CL`, `M_VLL`, `M_CTO`       | Пределы напряжения, В, тока, А, скорости, °/с, тайм-аут уставок, мс                                                                   |
| `M_Torq`, `M_Mod`                      | Режим момента (0 напряжение, 1 оценка тока, 2 модуль тока, 3 FOC по току) и модуляция (0 SPWM, 1 SVM, 2 Trap 120, 3 Trap 150)         |
| `C_*`, `V_*`, `A_*`                    | ПИД тока, скорости (на °/с) и П угла (предел °/с, разгон °/с²)                                                                        |
| `S_Gain`, `S_Off*`, `S_VTf`, `S_CTf`   | Датчик тока: чувствительность, В/А, нули фаз, В, фильтры скорости и тока, с                                                           |
| `TuneHz`, `Run`                        | Полоса автонастройки, Гц; `Run` 1 - запустить автонастройку                                                                           |

</details>
