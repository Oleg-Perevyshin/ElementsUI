# ProgressBar

Одна или несколько полос заполнения: уровень жидкости, заряд батареи, загрузка процессора.

## Назначение

Одна или несколько полос заполнения.

## Пакет данных

- Читает одну переменную со значениями всех полос.
- Только показывает, ничего не отправляет.

## Ключи

| Ключ | Описание |
|---|---|
| `<переменная>` | Массив `[{ "Value": 75 }, ...]`, по элементу на полосу. `Value` число в пределах шкалы |

## Особенности

- Полосы сопоставляются с данными по порядку, а не по имени. Порядок в настройках и в данных должен совпадать.
- Значение за пределами шкалы прижимается к краю.
- Полоса бывает горизонтальной и вертикальной. Вертикальной задайте высоту контейнера.
- Над полосой подпись и значение с единицами. Если у значения есть `Info`, оно выводится под полосой.

## Пропсы

| Название | Тип | По умолчанию | Описание |
|---|---|---|---|
| `id` | `string` | `crypto.randomUUID()` | Идентификатор |
| `wrapperClass` | `string` | `""` | Классы обёртки |
| `items` | `{ name?, class? }[]` | `[{ name: "Label" }]` | Полосы: подпись и классы |
| `value` | `{ Name?, Value, Info?, Timestamp? }[]` | | Значения по порядку полос. `Name` заменяет подпись из `items` |
| `type` | `"horizontal" \| "vertical"` | `"horizontal"` | Направление |
| `number.minNum`, `number.maxNum` | `number` | `0`, `100` | Пределы шкалы |
| `number.units` | `string` | `"%"` | Единицы |

Колбэков нет.

## Пример

```svelte
<UI.ProgressBar
  items={[{ name: "CPU" }, { name: "RAM", class: "bg-green" }]}
  value={[{ Value: 42 }, { Value: 67, Info: "5.4 из 8 ГБ" }]}
/>
```

## Панель свойств (ProgressBarProps.svelte)

В конструкторе задают полосы, направление, пределы шкалы и единицы.
