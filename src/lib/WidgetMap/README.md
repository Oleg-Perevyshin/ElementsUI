# WidgetMap

Смарт-виджет «Карта»: где находятся объекты, куда они смотрят и как двигались. Каждый объект это одна группа полей устройства, на одной карте их может быть несколько. Ещё два режима строят миссию: «Маршрут» - обычный планировщик из точек с высотами, «Агро» - генератор миссии для агродрона. Аппараты из групп полей видны во всех режимах. Карта на MapLibre.

## Назначение

Карта объектов в реальном времени: положение, курс и траектория каждого объекта.

Ширина виджета равна ширине контейнера, высоту карты задаёт `height`. В сетке конструктора виджет занимает одну строку.

## Пакет данных

- Работает с полями групп устройства, по группе на объект. По умолчанию `MAV`. Несколько групп пишут через пробел: `MAV GNSS`, например автопилот и собственный GNSS-приёмник модуля.
- Координаты приходят потоком телеметрии раз в 0.5-1 секунды, имя и серийный номер реже.
- Только показывает, ничего не отправляет.

## Ключи

| Ключ         | Описание                                                                              |
| ------------ | ------------------------------------------------------------------------------------- |
| `Lat`, `Lon` | Широта и долгота, °. Обязательны. Если оба равны 0, фиксации нет и объект не рисуется |
| `Alt`        | Высота, м                                                                             |
| `Heading`    | Курс, 0-360°. Поворачивает маркер                                                     |
| `Sat`        | Число спутников                                                                       |
| `DevName`    | Имя объекта, подпись маркера. Без него подписью будет имя группы                      |
| `DevSN`      | Серийный номер                                                                        |
| `WPNum`      | Номер текущей команды миссии. Нужен только режимам «Маршрут» и «Агро» для прогресса   |

Имена ключей общие с `WidgetPFD` и `WidgetDeviceInfo`. Одна отправка телеметрии кормит и карту, и пилотажный дисплей.

## Как подключить

1. **Прошивка** шлёт поля группы потоком телеметрии (`Telemetry_SendObject`, ключ `Data`). Облако и WebApp раскладывают их в переменные `<ModSN>|<группа>.<ключ>`. Имя и серийный номер шлют отдельным кадром раз в несколько секунд: буфер `Telemetry_SendObject` 512 байт, и строки в нём занимают много места.
2. **В конструкторе** добавьте «Карту» из смарт-виджетов и перечислите группы через пробел. Привязывать переменные не нужно.
3. **Оператор** на самой карте включает траекторию, выбирает число её точек и через сколько скрывать молчащие объекты.

```c
/* Группа MAV: те же ключи читает WidgetPFD */
const telemetry_kv_t mav[] = {
    TLM_F("MAV.Lat", lat_deg), TLM_F("MAV.Lon", lon_deg), TLM_F("MAV.Alt", alt_m),
    TLM_F("MAV.Heading", hdg_deg), TLM_F("MAV.Sat", (float) sats),
};
Telemetry_SendObject(g_telemetry_stream, g_mcfg.DevSN, "Data", mav, sizeof(mav) / sizeof(mav[0])); /* раз в 0.5 с */

/* Имя и серийный номер отдельным кадром раз в несколько секунд */
const telemetry_kv_t dev[] = {TLM_S("MAV.DevName", g_mcfg.DevName), TLM_S("MAV.DevSN", g_mcfg.DevSN)};
Telemetry_SendObject(g_telemetry_stream, g_mcfg.DevSN, "Data", dev, sizeof(dev) / sizeof(dev[0]));
```

## Особенности

- **Свежесть.** Маркер зелёный, пока значения объекта менялись в пределах таймаута. Без изменений он красный, а ещё через таймаут скрывается до новых данных.
- **Траектория.** Точка добавляется только при смене координат. Курс и высота могут меняться чаще.
- **«Показать все»** в шапке вписывает все видимые объекты в экран, один объект приближает. Сама карта вид не меняет, ведь объектов может быть много.
- **Клик по маркеру** открывает карточку: имя, группа, координаты, высота, курс, спутники, серийный номер. Кнопки «Копировать» (всё в буфер обмена) и «Скрыть» (до следующего обновления объекта).
- **Слежение.** Кнопка «Следить» в карточке залипает. Один отслеживаемый объект всегда в центре карты. Несколько вписываются в карту при включении слежения, дальше карта держит в центре их середину. Масштаб остаётся за оператором: карта сама отдаляется, только когда объект уходит за край. Под маркером отслеживаемого объекта точка, она видна и при закрытой карточке. Если объект пропал с карты, слежение за ним продолжится, когда он появится снова. «Скрыть» снимает слежение.
- **Шапка** показывает, сколько объектов на связи. Зелёный значит все, серый часть, красный ни одного.
- **Только 2D.** Наклонить карту нельзя. Правая кнопка мыши только поворачивает карту, компас под кнопками масштаба возвращает её на север.
- Карта светлая или тёмная по теме страницы и переключается вместе с ней.
- MapLibre загружается с CDN один раз на страницу. Без интернета видна заглушка «Карта не загружена».
- Источник подложки (CARTO и OpenStreetMap) указывать обязательно. Подпись свёрнута в кнопку «i» в углу карты.
- Сворачивание, мастер-цвет и кнопка «?» с подсказками работают как у `WidgetWiFi`.

## Режим имитации

`isTest` включает имитацию шести аппаратов `SIM-1`-`SIM-6` без устройства. Они летают над одним районом Минска, в пределах пары километров, и обновляются раз в полсекунды. На связи всегда три аппарата. Через 40-100 секунд один из них пропадает, и его сразу сменяет тот, кто молчит дольше всех. Поэтому видно все состояния маркера: свежий, красный устаревший, скрытый и снова появившийся. При включении карта переходит к этому району. Пока режим включён, `value` и `groups` не учитываются. В конструкторе все остальные свойства становятся бледными и недоступными, пока имитацию не выключат.

В режимах «Маршрут» и «Агро» `isTest` включает имитацию полёта по рассчитанной траектории. Аппарат летит по маршруту со скоростями его точек или по проходам «Агро» и оставляет голубой след. В «Агро» маркер - квадрокоптер, он зелёный, пока идёт распыление. Панель поверх карты показывает время полёта, процент пройденного пути, высоту, скорость и распыление; там же запуск и пауза, ускорение ×1, ×5, ×10 или ×25 (по умолчанию ×5) и полоса прокрутки пути: её перетаскивание ставит полёт на паузу, чтобы рассмотреть любое место траектории. Полёт запускается вручную кнопкой ▶ и останавливается в конце пути; повторный запуск начинает его заново. При любом изменении маршрута или полей аппарат возвращается в начало и встаёт на паузу. Аппараты из `groups` в это время не рисуются.

## Режим «Маршрут»

`mode="route"` - обычный планировщик миссии: точки по порядку облёта, у каждой своя высота и скорость. Аппараты из `groups` рисуются поверх маршрута, как в режиме «Объекты».

1. **«Изменить точки»** включает правку. Клик по карте добавляет точку в конец маршрута. Новая точка берёт высоту и скорость предыдущей, первая получает 30 м и 8 м/с. Esc или двойной клик заканчивают правку.
2. В режиме правки точки можно перетаскивать. Потяните за середину отрезка, чтобы вставить точку между соседними. Правый клик удаляет точку. Без правки на карте видны только номера точек, их не сдвинуть случайно. Точку взлёта `H` можно перетаскивать всегда.
3. Блок **«Итог»**: сверху расчёт (число точек, длина пути, время, наибольшая высота), ниже список точек с высотой, скоростью, расстоянием от предыдущей точки и удалением; порядок меняется перетаскиванием строки за ручку, как в списках панелей свойств, под ним флажок возврата с посадкой (RTL). Клик по номеру показывает точку на карте.

Миссия в формате QGC WPL 110: точка дома, `NAV_TAKEOFF` на высоту первой точки, точки маршрута со своими высотами, `DO_CHANGE_SPEED` перед точкой, где меняется скорость, в конце `RTL`, если включён возврат. Высоты отсчитываются от точки взлёта. Время: каждый отрезок со скоростью своей точки плюс набор высоты и посадка около 2.5 м/с.

План хранит владелец карты через `route` и `onRouteChange`. Без `route` показывается демо-облёт вокруг поля под Минском.

| Поле `IRoutePlan` | Описание                                                                                                     |
| ----------------- | ------------------------------------------------------------------------------------------------------------ |
| `start`           | Точка взлёта, `[lng, lat]`                                                                                   |
| `points`          | Точки `{ point: [lng, lat], alt, speed }`: высота в метрах над точкой взлёта, скорость на пути к точке в м/с |
| `returnHome`      | Вернуться и сесть в конце (RTL)                                                                              |

### Прогресс в шапке

В «Маршруте» и «Агро» шапка показывает полоску и процент выполнения миссии. В режиме имитации это прогресс имитации. Без имитации прогресс считается по телеметрии первой группы карты: `WPNum` (номер команды миссии, которую выполняет автопилот) и положение аппарата. Если текущая команда служебная (скорость, распылитель), целью считается следующая точка. Внутри отрезка учитывается, сколько аппарат уже пролетел к цели. В «Маршруте» рядом видно «к точке 3/6» или «возврат», в «Агро» - сколько гектаров обработано. Прогресс верен, только если на борту та же миссия, что построена на карте. Без `WPNum` полоски нет.

## Режим «Агро»

`mode="agro"` превращает карту в генератор миссии для агродрона. Оператор обводит на карте одно или несколько полей и запретные зоны, задаёт угол проходов и ширину захвата. Карта строит траекторию, которая покрывает все поля, обходит зоны и выключает распылитель на разворотах и переходах. Готовую миссию можно скачать, скопировать или отправить на борт в формате QGC WPL 110 для автопилота ArduPilot.

Аппараты из `groups` рисуются поверх миссии так же, как в режиме «Объекты»: маркер, карточка по клику и траектория, если она включена. План хранит владелец карты через `plan` и `onPlanChange`, миссия уходит наружу через `onSend`. Без `plan` показываются два демо-поля под Минском: в большом три запретные зоны, в малом вырез и дерево.

### Как пользоваться

1. **«Нарисовать поле»**: кликами по карте обведите участок. Контур замыкается кликом по первой точке, двойным кликом, Enter или кнопкой «Замкнуть». Backspace убирает последнюю точку, Esc сбрасывает начатый контур. Когда поле есть, кнопка называется **«Поля»**: в этом режиме клики по карте обводят ещё одно поле.
2. **«Запретные зоны»**: обведите места, где нельзя лететь и распылять: деревья, опоры ЛЭП, постройки, водоёмы. Зон может быть сколько угодно.
3. **Точка взлёта** (синяя) видна всегда, её можно перетащить в любой момент.
4. В блоке **«Маршрут и внесение»** задайте ширину захвата, отступ от границ, высоту, скорость, норму внесения и объём бака. У каждого поля свой угол проходов: новое поле сразу получает лучший угол, «Авторасчёт» пересчитывает углы всех полей приближениями по полному расчёту траектории: шаг 5° по всем направлениям и вдоль сторон поля, затем 1° около трёх лучших, затем 0,1° около победителя; лучший угол даёт наименьшее время облёта с учётом разворотов. Пока идёт расчёт, на карте видно колесо ожидания «Расчёт оптимального маршрута» с полосой и процентом (на большом поле это несколько секунд), а ползунок «Угол для всех полей» ставит всем один угол, например чтобы проходы шли вдоль рядов посадки. Угол отдельного поля правится в его строке в блоке «Итог».
5. Блок **«Итог»** показывает контуры, площадь к обработке, покрытие, длину пути, время, расход раствора и число дозаправок.
6. **«Скачать»**, **«Копировать»** или **«Отправить»** миссию.

Точки контуров видны и перетаскиваются, только пока нажата кнопка «Поля» или «Запретные зоны». Потяните за середину стороны, чтобы добавить точку. Правый клик удаляет точку. Поля и зоны удаляются крестиком в блоке «Итог». Режим выключается той же кнопкой, кнопкой «Готово» или Esc.

### Как строится траектория

1. Поле переводится в метры и поворачивается так, чтобы проходы шли вдоль оси.
2. Для каждого прохода считаются свободные отрезки: внутри поля и вне зон, с отступом по всей ширине полосы.
3. Отрезки собираются в участки: подряд идущие проходы, которые соединяются один к одному. Каждый участок облетается змейкой.
4. Порядок участков и сторона входа выбираются точным перебором, если участков не больше 10. Если больше, используется жадный выбор с улучшением 2-opt.
5. Переходы между участками идут по кратчайшему пути в обход зон с соблюдением отступа.
6. Несколько полей облетаются по очереди: каждый раз ближайшее к текущему положению. Путь к первому полю, переходы между полями и возврат домой строятся по открытой местности в обход всех зон.

Расчёт занимает 15-30 мс, траектория пересчитывается на каждое изменение.

### Миссия

- точка дома (точка взлёта или первая точка поля);
- `DO_CHANGE_SPEED` с заданной скоростью;
- точки маршрута на заданной высоте над точкой взлёта;
- команды распыления: включение в начале прохода, выключение в конце и перед вылетом.

| Режим распыления      | Команда              | Что нужно на борту                                                |
| --------------------- | -------------------- | ----------------------------------------------------------------- |
| Распылитель ArduPilot | `DO_SPRAYER` (216)   | `SPRAY_ENABLE=1`, выход насоса `SERVOx_FUNCTION=22`               |
| Насос на выходе       | `DO_SET_SERVO` (183) | канал и ШИМ вкл./выкл. задаются на карте                          |
| Без команд            | нет                  | распылитель работает и на разворотах, участки обработаются дважды |

Кнопка «Отправить» неактивна, если не передан `onSend`. Во время отправки на ней «Отправка…», после успеха «Отправлено», при ошибке она краснеет. Время полёта считается по скорости плюс около 4 с на разворот. Покрытие - доля поля без зон, которая попадает под распыление: остальное съедают отступы.

### План миссии (IMissionPlan)

| Поле                                  | Описание                                                                                |
| ------------------------------------- | --------------------------------------------------------------------------------------- |
| `fields`                              | Поля `{ contour: [lng, lat][], angle }`: контур и угол проходов, ° от севера по часовой |
| `holes`                               | Запретные зоны, массив контуров; зона относится к полю, внутри которого лежит её центр  |
| `start`                               | Точка взлёта, `[lng, lat]`                                                              |
| `spacing`                             | Ширина захвата, м                                                                       |
| `margin`                              | Отступ от границ и зон, м                                                               |
| `alt`, `speed`                        | Высота, м, и скорость, м/с                                                              |
| `returnHome`                          | Вернуться к точке взлёта в конце                                                        |
| `rate`, `tank`                        | Норма внесения, л/га, и объём бака, л                                                   |
| `sprayControl`                        | `sprayer`, `servo` или `none`                                                           |
| `servoChannel`, `servoOn`, `servoOff` | Канал и ШИМ насоса для режима `servo`                                                   |

Расчёт доступен и без карты: `planFields` (несколько полей), `planCoverage` (одно поле), `bestFieldAngle`, `toWaypointsFile` экспортируются из библиотеки.

## Пример

```svelte
<UI.WidgetMap groups={["MAV", "GNSS"]} value={{ MAV: mav, GNSS: gnss }} height={400} trackEnabled />

<UI.WidgetMap mode="route" bind:route groups={["MAV"]} value={{ MAV: mav }} onSend={(mission) => sendToDevice(mission)} />

<UI.WidgetMap mode="agro" bind:plan groups={["MAV"]} value={{ MAV: mav }} onSend={(mission) => sendToDevice(mission)} />
```

В DevCloud и WebApp `value` собирает `GUIPreview`: для каждой группы читает переменные `<ModSN>|<группа>.<ключ>`.

## Панель свойств (WidgetMapProps.svelte)

В конструкторе задают режим («Объекты», «Маршрут» или «Агро»), заголовок, группы через пробел, мастер-цвет, высоту карты (S, M, L, XL: 250, 400, 600, 800 пикселей), иконку маркера и начальные значения траектории. Группы, иконка маркера, траектория и имитация действуют во всех режимах.

## Внутреннее устройство

В папке `mapWrapper/` лежат тонкие Svelte-обёртки над MapLibre GL: `MapLibre`, `Marker`, `Popup`, `Line`, элементы управления и `CustomControl` для своих кнопок поверх карты.

В папке `mission/` лежат режимы построения миссии: `MapRoute.svelte` и `route.ts` (режим «Маршрут»), `MapAgro.svelte` (интерфейс режима «Агро»), `coverage.ts` (расчёт траектории и выгрузка миссии), `plan.ts` (тип плана и план по умолчанию), `MissionLayers.svelte` (слои карты и перетаскивание точек).
