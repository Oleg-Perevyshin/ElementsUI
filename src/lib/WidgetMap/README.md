# WidgetMap Component

## Назначение

Карта объектов в реальном времени: положение, курс и траектория каждого объекта.

> **Размеры.** Ширина — 100% контейнера (в конструкторе — ширина ячейки сетки); высота карты задаётся пропом `height` (px), в сетке конструктора виджет занимает одну строку. Мастер-цвет (`componentClass`) перекрашивает шапку.

## Пакет данных

- Поля групп устройства, по группе на объект: по умолчанию `MAV`, несколько — через пробел (`MAV GNSS`); привязывать переменные не нужно
- Поток телеметрии: координаты — раз в 0.5–1 с, имя и серийный номер — реже
- Только отображение, ничего не отправляет

### Как работать с картой

1. **Устройство** шлёт поля группы в поток телеметрии (`Telemetry_SendObject`, ключ `Data`) — облако и WebApp раскладывают их в переменные `<ModSN>|<группа>.<ключ>`. Координаты — раз в 0.5–1 с, имя и серийный номер — реже (раз в несколько секунд) отдельным кадром: буфер `Telemetry_SendObject` — 512 байт, строки его быстро съедают.
2. **В конструкторе** добавьте «Карту» из смарт-виджетов и перечислите группы через пробел (`MAV` или `MAV GNSS`). Переменные привязывать не нужно — виджет сам берёт ключи из таблицы ниже.
3. **Оператор** поверх карты включает траекторию, выбирает число её точек и таймаут маркеров. Кнопка **«Показать все»** в шапке виджета вписывает все видимые объекты в экран (один объект — приближение к нему). Сама карта вид не меняет — объектов может быть много.
4. **Клик по маркеру** открывает карточку объекта: имя, группа, координаты, высота, курс, спутники, серийный номер; кнопки «Копировать» (всё в буфер обмена) и «Скрыть» (до следующего обновления объекта).

```c
/* Прошивка: группа MAV — те же ключи читает и WidgetPFD, одна отправка кормит оба виджета */
const telemetry_kv_t mav[] = {
    TLM_F("MAV.Lat", lat_deg),     TLM_F("MAV.Lon", lon_deg),       TLM_F("MAV.Alt", alt_m),
    TLM_F("MAV.Heading", hdg_deg), TLM_F("MAV.Sat", (float) sats),
};
Telemetry_SendObject(g_telemetry_stream, g_mcfg.DevSN, "Data", mav, sizeof(mav) / sizeof(mav[0])); /* раз в 0.5 с */

/* Имя и серийный номер — отдельным кадром раз в несколько секунд */
const telemetry_kv_t dev[] = {TLM_S("MAV.DevName", g_mcfg.DevName), TLM_S("MAV.DevSN", g_mcfg.DevSN)};
Telemetry_SendObject(g_telemetry_stream, g_mcfg.DevSN, "Data", dev, sizeof(dev) / sizeof(dev[0]));
```

## Ключи

| Ключ      | Описание                                                                          |
| --------- | --------------------------------------------------------------------------------- |
| `Lat`     | число, °: широта, обязательный; `Lat` и `Lon` = 0 — нет фикса, объект не рисуется |
| `Lon`     | число, °: долгота, обязательный                                                   |
| `Alt`     | число, м: высота                                                                  |
| `Heading` | число, 0–360°: курс, поворачивает маркер                                          |
| `Sat`     | число спутников                                                                   |
| `DevName` | строка: имя объекта, подпись маркера; без него — имя группы                       |
| `DevSN`   | строка: серийный номер                                                            |

## Особенности

Смарт-виджет «Карта» — положение объектов на карте MapLibre с траекториями. Каждый объект — одна **группа полей** устройства (префикс, например `MAV`); виджет показывает сразу несколько групп, например `MAV GNSS` — автопилот и собственный GNSS-приёмник модуля. Только отображение: ничего не отправляет и не знает про DeviceStore/WebSocket. Заменяет удалённый компонент `Map`.

### Поведение

- **Свежесть.** Объект зелёный, пока его значения менялись за таймаут; без изменений — красный; ещё через таймаут скрывается до новых данных.
- **Траектория** — точка добавляется только при смене координат (курс и высота могут обновляться чаще позиции).
- **Только 2D** — наклон (3D) запрещён; правой кнопкой мыши карта только поворачивается, кнопка-компас под зумом возвращает её на север.
- **Шапка** — сколько объектов на связи из заданных: зелёный — все, серый — часть, красный — ни одного.
- Карта светлая/тёмная по ближайшему предку `.dark`/`.light` (как токены `theme.css`), пересчёт по событию `ThemeChange`.

## Пропсы

| Название         | Тип                                             | По умолчанию | Описание                                                        |
| ---------------- | ----------------------------------------------- | ------------ | --------------------------------------------------------------- |
| `wrapperClass`   | `string`                                        | `""`         | CSS-классы обёртки                                              |
| `componentClass` | `string`                                        | `""`         | «Мастер-цвет» виджета — роль вида `"bg-blue"`                   |
| `label`          | `{ name?: string }`                             | `{}`         | Заголовок карточки; пустой — «Карта» на текущем языке           |
| `groups`         | `string[]`                                      | `["MAV"]`    | Префиксы групп полей — по объекту на группу                     |
| `value`          | `Record<string, Partial<IWidgetMapData>>`       | `undefined`  | Значения по группам: `{ MAV: { Lat, Lon, ... }, GNSS: {...} }`  |
| `keys`           | `Partial<Record<keyof IWidgetMapData, string>>` | `undefined`  | Переопределение имён ключей (применяет GUIPreview)              |
| `height`         | `number`                                        | `400`        | Высота карты, px                                                |
| `markerIcon`     | `ConstructorOfATypedSvelteComponent \| string`  | `undefined`  | Иконка маркера (SVG-строка или компонент), по умолчанию стрелка |
| `trackEnabled`   | `boolean`                                       | `false`      | Начальное состояние «Траектория» (`$bindable`)                  |
| `trackLength`    | `number`                                        | `1000`       | Начальное число точек траектории (`$bindable`)                  |
| `markerTimeout`  | `number`                                        | `30000`      | Начальный таймаут маркеров, мс (`$bindable`)                    |
| `collapsed`      | `boolean`                                       | `false`      | Свёрнуто ли тело виджета (`$bindable`)                          |
| `persistKey`     | `string`                                        | `undefined`  | Ключ для сохранения `collapsed` в `localStorage`                |

## Примеры

```svelte
<UI.WidgetMap groups={["MAV", "GNSS"]} value={{ MAV: mav, GNSS: gnss }} height={400} trackEnabled />
```

В DevCloud и WebApp `value` собирает GUIPreview: для каждой группы читает `<ModSN>|<группа>.<ключ>` по таблице выше.

## Конструктор свойств (WidgetMapProps.svelte)

Группы панели: общие (заголовок, группы полей через пробел, мастер-цвет), оформление (высота карты S/M/L/XL — 250/400/600/800 px, иконка маркера), по умолчанию (траектория и её длина — оператор меняет их на карте).

### Что настраивается

- Группы полей, мастер-цвет
- Высота карты `S`/`M`/`L`/`XL`, иконка маркера
- Начальные значения: траектория и число её точек

## Внутреннее устройство

`mapWrapper/` — тонкие Svelte-обёртки над MapLibre GL (`MapLibre`, `Marker`, `Popup`, `Line`, контролы, `CustomControl` для своих элементов поверх карты). MapLibre подгружается с CDN один раз на страницу (несколько карт ждут одну загрузку); без интернета показывается заглушка «Карта не загружена».

### Подсказки

Кнопка «?» в правом краю шапки включает и выключает подсказки этого виджета; выбор общий для всех `WidgetMap` в браузере (`hintsSetting("WidgetMap")`, `hints.ts`). Подсказка всплывает при наведении на поле, смысл которого не очевиден, — что это за значение и на что влияет.
