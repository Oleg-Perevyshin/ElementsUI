# WidgetMap Component

## Описание

> **Размеры.** Ширина — 100% контейнера (в конструкторе — ширина ячейки сетки); высота карты задаётся пропом `height` (px), в сетке конструктора виджет занимает одну строку. Мастер-цвет (`componentClass`) перекрашивает шапку.

Смарт-виджет «Карта» — положение бортов на карте MapLibre с траекториями. Работает с полями групп устройства
(по умолчанию `MAV`): каждая группа из `groups` — отдельный борт со своим маркером и своей траекторией, например
`["MAV", "GNSS"]` — позиция автопилота и собственного GNSS-приёмника модуля. Только отображение: ничего не
отправляет и не знает про DeviceStore/WebSocket. Заменяет удалённый компонент `Map`.

- **Поверх карты** (решает оператор): траектория вкл/выкл и число её точек, таймаут маркеров, кнопка «Все борта»
  (иконка рамки под зумом и полноэкранным режимом) — вписывает в экран все видимые борта, один борт — приближение
  к нему (зум 16). Сама карта вид не меняет.
- **Свежесть.** Борт зелёный, пока его значения менялись за таймаут; без изменений — красный; ещё через таймаут
  скрывается до новых данных. Кнопка в карточке борта скрывает его до следующего изменения.
- **Траектория** — точка добавляется только при смене координат (курс и высота могут обновляться чаще позиции).
- **Шапка** — сколько бортов на связи из заданных: зелёный — все, серый — часть, красный — ни одного.
- Карта светлая/тёмная по теме приложения (событие `ThemeChange`).

## Поля группы

| Поле      | Что                                       |
| --------- | ----------------------------------------- |
| `Lat`     | широта, °; вместе с `Lon` = 0 — нет фикса |
| `Lon`     | долгота, °                                |
| `Alt`     | высота, м — в карточке борта              |
| `Heading` | курс, 0..360° — поворот маркера           |
| `Sat`     | спутников — в карточке борта              |

В DevCloud и WebApp GUIPreview собирает `value` сам: `{ [группа]: { Lat: <ModSN>|<группа>.Lat, ... } }`.

## Пропсы

| Название         | Тип                                             | По умолчанию        | Описание                                                        |
| ---------------- | ----------------------------------------------- | ------------------- | --------------------------------------------------------------- |
| `wrapperClass`   | `string`                                        | `""`                | CSS-классы обёртки                                              |
| `componentClass` | `string`                                        | `""`                | «Мастер-цвет» виджета — роль вида `"bg-blue"`                   |
| `label`          | `{ name?: string }`                             | `{ name: "Карта" }` | Заголовок карточки                                              |
| `groups`         | `string[]`                                      | `["MAV"]`           | Префиксы групп полей — по борту на группу                       |
| `value`          | `Record<string, Partial<IWidgetMapData>>`       | `undefined`         | Значения по группам                                             |
| `keys`           | `Partial<Record<keyof IWidgetMapData, string>>` | `undefined`         | Переопределение имён полей устройства (используется GUIPreview) |
| `height`         | `number`                                        | `400`               | Высота карты, px                                                |
| `markerIcon`     | `ConstructorOfATypedSvelteComponent \| string`  | `undefined`         | Иконка маркера (SVG-строка или компонент), по умолчанию стрелка |
| `trackEnabled`   | `boolean`                                       | `false`             | Начальное состояние «Траектория» (`$bindable`)                  |
| `trackLength`    | `number`                                        | `1000`              | Начальное число точек траектории (`$bindable`)                  |
| `markerTimeout`  | `number`                                        | `30000`             | Начальный таймаут маркеров, мс (`$bindable`)                    |
| `collapsed`      | `boolean`                                       | `false`             | Свёрнуто ли тело виджета (`$bindable`)                          |
| `persistKey`     | `string`                                        | `undefined`         | Ключ для сохранения `collapsed` в `localStorage`                |

## Пример

```svelte
<UI.WidgetMap groups={["MAV", "GNSS"]} value={{ MAV: mav, GNSS: gnss }} height={400} trackEnabled />
```

## Конструктор свойств (WidgetMapProps.svelte)

Группы панели: общие (заголовок, группы полей через запятую, мастер-цвет), оформление (высота карты, иконка
маркера), по умолчанию (траектория и её длина — оператор меняет их на карте).

## Внутренняя архитектура

`mapWrapper/` — тонкие Svelte-обёртки над MapLibre GL (`MapLibre`, `Marker`, `Popup`, `Line`, контролы,
`CustomControl` для своих элементов поверх карты). MapLibre подгружается при монтировании; без интернета
показывается заглушка «Карта не загружена».
