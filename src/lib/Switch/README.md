# Switch

Переключатель «включено/выключено»: реле, режим, флаг. Бывает тумблером, вертикальным тумблером и галочкой. Может управлять отдельными битами одного числа.

## Назначение

Включение и выключение: реле, режимы, флаги.

## Пакет данных

- Читает и пишет одну переменную.
- Значение отправляется сразу при переключении.
- Отправка настраивается в событии: **Заголовок** (обычно `SET`) и **Аргумент** (обычно `ModCfg`). С `NoSend` значение сразу не уходит, его отправит другой компонент.

## Ключи

| Ключ | Описание |
|---|---|
| `<переменная>` | `0` или `1`. В битовом режиме целое число-маска, каждый переключатель управляет своим битом 0-31 |

## Особенности

- **Обычный режим.** Один тумблер, значение 0 или 1. Подписи `captionLeft` и `captionRight` по бокам тоже кликабельны: левая ставит 0, правая ставит 1.
- **Битовый режим** (`bitMode`). Каждый вариант из `options` это свой тумблер со своим битом (`value` варианта это номер бита). Значение это маска из всех битов, до 32. Галочки в битовом режиме нет.
- **Галочка** (`type="checkbox"`). Без подписей по бокам, вместо них подсказка `hiddenInfo` при наведении. `options` можно не передавать.
- Размер тумблера задаёт `height`. Ширина горизонтального тумблера в два раза больше высоты.
- Заголовок по умолчанию по центру. `text-left` или `text-right` в `label.class` меняют выравнивание.

## Пропсы

| Название | Тип | По умолчанию | Описание |
|---|---|---|---|
| `id` | `string` | `crypto.randomUUID()` | Идентификатор |
| `type` | `"horizontal" \| "vertical" \| "checkbox"` | `"horizontal"` | Вид |
| `value` | `number` | | 0 или 1, в битовом режиме маска. Можно связать через `bind:value` |
| `bitMode` | `boolean` | `false` | Битовый режим |
| `options` | `IOption<number>[]` | `[]` | Варианты: `name` подпись над тумблером, `value` номер бита |
| `height` | `string` | `"1.625rem"` | Высота тумблера |
| `label.name`, `label.class` | `string` | `""` | Заголовок и его классы |
| `label.captionLeft`, `label.captionRight` | `string` | `""` | Подписи слева и справа |
| `hiddenInfo` | `string` | `""` | Подсказка для галочки |
| `wrapperClass` | `string` | `""` | Классы обёртки |
| `disabled` | `boolean` | `false` | Неактивен |
| `onChange` | `(value: number) => void` | | Значение изменилось |

## Примеры

```svelte
<script>
  import * as UI from "poe-svelte-ui-lib"
  let relay = $state(0)
  let flags = $state(0b101)
</script>

<UI.Switch label={{ name: "Реле 1", captionLeft: "Выкл", captionRight: "Вкл" }} bind:value={relay} />

<UI.Switch
  label={{ name: "Каналы" }}
  bitMode
  options={[{ id: "a", name: "1", value: 0 }, { id: "b", name: "2", value: 1 }, { id: "c", name: "3", value: 2 }]}
  bind:value={flags}
/>

<UI.Switch type="checkbox" hiddenInfo="Запомнить" bind:value={relay} />
```

## Панель свойств (SwitchProps.svelte)

В конструкторе задают вид, подписи, битовый режим и его тумблеры, событие отправки.
