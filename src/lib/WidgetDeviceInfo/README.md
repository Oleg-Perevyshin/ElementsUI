# WidgetDeviceInfo

Смарт-виджет «Об устройстве»: серийный номер, версия прошивки, имя устройства, доступ к веб-интерфейсу, перезагрузка и сброс настроек.

## Назначение

Паспорт устройства и его основные настройки.

Ширина виджета равна ширине контейнера, высота по содержимому. В сетке конструктора он занимает одну строку.

## Пакет данных

- Работает с полями группы `CFG`. Группу можно сменить префиксом в настройках.
- «Сохранить» отправляет изменённые поля одним пакетом `SET ModCfg`.
- «Перезагрузить» отправляет `SET Restart`.
- «Сброс настроек» после подтверждения отправляет `SET RstNVS`. Прошивка стирает все настройки и перезагружается.

## Ключи

| Ключ | Описание |
|---|---|
| `DevSN` | Серийный номер, только чтение |
| `DevID` | Код изделия, только чтение |
| `DevFW` | Версия прошивки, только чтение |
| `RunCnt` | Сколько раз устройство включалось, только чтение |
| `StaIP`, `ApIP` | Текущие адреса в сети роутера и своей точки доступа, только чтение |
| `DevName` | Имя устройства: латиница, цифры, `_`, `-` и `.`, до 15 символов |
| `HostName` | Сетевое имя без `.local`, домен добавляет устройство. Латиница, цифры, `_` и `-`, до 18 символов |
| `WebUser`, `WebPsw` | Логин и пароль веб-интерфейса, до 15 символов. Логин: латиница, цифры, `_` и `-`. Пароль: любые печатные символы ASCII без пробела |

## Особенности

- Серийный номер длинный, поэтому стоит отдельной строкой и не обрезается.
- Ограничения полей указаны в подсказках. Неверный ввод не сохраняется.
- Кнопка сброса появляется, только если передан `onFactoryReset`.
- Мастер-цвет, сворачивание, запоминание свёрнутого состояния и кнопка «?» с подсказками работают так же, как у `WidgetWiFi`.
- Сам виджет с устройством не говорит. Читает и пишет поля приложение.

## Пропсы

| Название | Тип | По умолчанию | Описание |
|---|---|---|---|
| `id` | `string` | `"CFG"` | Префикс группы полей |
| `keys` | `Partial<Record<ключ, string>>` | имена ключей | Другие имена полей |
| `value` | `IWidgetDeviceInfoConfig` | | Текущие значения |
| `label.name` | `string` | | Заголовок. Пусто - «Об устройстве» на языке пользователя |
| `wrapperClass` | `string` | `""` | Классы обёртки |
| `componentClass` | `string` | `""` | Мастер-цвет `bg-*` |
| `restartCommand` | `{ header, argument }` | `SET`, `Restart` | Команда перезагрузки |
| `resetCommand` | `{ header, argument }` | `SET`, `RstNVS` | Команда сброса настроек |
| `collapsed` | `boolean` | `false` | Свёрнут ли |
| `persistKey` | `string` | | Ключ для запоминания свёрнутого состояния |
| `onSave` | `(info) => void` | | Нажата «Сохранить» |
| `onRestart` | `() => void` | | Нажата «Перезагрузить» |
| `onFactoryReset` | `() => void` | | Сброс подтверждён |

## Пример

```svelte
<UI.WidgetDeviceInfo
  value={{
    DevSN: "00.00.000-00_0000AC670000B22B00007428:DBC5",
    DevID: "00.00.000-00",
    DevFW: 1,
    RunCnt: 128,
    DevName: "Kitchen",
    HostName: "kitchen",
    WebUser: "admin",
    WebPsw: "",
    StaIP: "192.168.1.40",
    ApIP: "192.168.4.1",
  }}
  onSave={(info) => sendModCfg(info)}
  onRestart={() => send("SET", "Restart")}
  onFactoryReset={() => send("SET", "RstNVS")}
/>
```

## Панель свойств (WidgetDeviceInfoProps.svelte)

В конструкторе задают заголовок, префикс группы, другие имена полей, команды перезагрузки и сброса и мастер-цвет.
