# WidgetPFD Component

## Назначение

Пилотажный дисплей (PFD) — главный прибор контроля полёта: пространственное положение, скорость, высота, курс и состояние систем.

> **Размеры.** Ширина — 100% контейнера (в конструкторе — ширина ячейки сетки), без собственного ограничения; высота — по содержимому, в сетке конструктора виджет занимает одну строку. Мастер-цвет (`componentClass`) перекрашивает шапку и рамки значений.

## Пакет данных

- Поля группы `MAV` — телеметрия автопилота MAVLink (меняется префиксом в настройках), привязывать переменные не нужно
- Поток телеметрии: `Roll`, `Pitch`, `Heading` — ~20 раз в секунду, остальное — 1–2 раза в секунду
- Только отображение, ничего не отправляет

### Протокол устройства

Поток телеметрии (`Telemetry_SendObject`, ключ `Data`) — облако раскладывает поля в значения группы:

| Поле                                     | Что                                             | Источник MAVLink             | Частота |
| ---------------------------------------- | ----------------------------------------------- | ---------------------------- | ------- |
| `MAV.Roll`, `MAV.Pitch`, `MAV.Heading`   | крен, тангаж, курс (°)                          | ATTITUDE                     | 20 Гц   |
| `MAV.GSpeed`, `MAV.ASpeed`, `MAV.Climb`  | путевая, воздушная, вертикальная скорость (м/с) | VFR_HUD                      | 2 Гц    |
| `MAV.Alt`, `MAV.AltMSL`                  | высота над взлётом и над морем (м)              | GLOBAL_POSITION_INT, VFR_HUD | 2 Гц    |
| `MAV.Lat`, `MAV.Lon`, `MAV.Vx`, `MAV.Vy` | координаты, скорость на север/восток            | GLOBAL_POSITION_INT          | 2 Гц    |
| `MAV.Fix`, `MAV.Sat`                     | тип фиксации, спутники                          | GPS_RAW_INT                  | 2 Гц    |
| `MAV.BV`, `MAV.BC`, `MAV.BRem`           | батарея: В, А (-1 нет), % (-1 нет)              | SYS_STATUS                   | 2 Гц    |
| `MAV.Mode`, `MAV.VType`, `MAV.Armed`     | custom_mode, MAV_TYPE, взведён                  | HEARTBEAT                    | 2 Гц    |
| `MAV.HomeLat`, `MAV.HomeLon`             | точка взлёта (0 — нет)                          | HOME_POSITION                | 2 Гц    |
| `MAV.Press`, `MAV.Temp`                  | давление (гПа), температура (°C)                | SCALED_PRESSURE              | 2 Гц    |

Расстояние и пеленг на дом, трек и возраст данных виджет считает сам.

## Ключи

| Ключ                 | Описание                                                                                            |
| -------------------- | --------------------------------------------------------------------------------------------------- |
| `Roll`, `Pitch`      | числа, °: крен (вправо +) и тангаж (вверх +)                                                        |
| `Heading`            | число, 0–360°: курс                                                                                 |
| `GSpeed`, `ASpeed`   | числа, м/с: путевая и воздушная скорость                                                            |
| `Alt`                | число, м: высота над точкой взлёта; `AltMSL` — над уровнем моря                                     |
| `Climb`              | число, м/с: вертикальная скорость (вверх +)                                                         |
| `Lat`, `Lon`         | числа, °: координаты                                                                                |
| `Vx`, `Vy`           | числа, м/с: скорость на север и восток — для трека                                                  |
| `Fix`                | число: тип фиксации GPS, `0`–`1` нет, `2` 2D, `3` 3D, `4`–`6` DGPS/RTK; `Sat` — число спутников     |
| `BV`                 | В; `BC` — А (`-1` не измеряется); `BRem` — % (`-1` неизвестно)                                      |
| `Mode`               | число: режим автопилота; `VType` — тип аппарата (по нему — названия режимов); `Armed` — `1` взведён |
| `HomeLat`, `HomeLon` | числа, °: точка взлёта, `0` — неизвестна                                                            |
| `Press`              | гПа, `Temp` — °C                                                                                    |

## Особенности

Смарт-виджет «Пилотажный дисплей» (Primary Flight Display) — главный прибор контроля полёта, как в
стеклянной кабине самолёта или наземной станции управления. Работает с полями группы (по умолчанию
`MAV`) ровно в том виде, в каком их отдаёт телеметрия автопилота MAVLink устройства 20.00.000-01.
Только отображение: ничего не отправляет и не знает про DeviceStore/WebSocket.

- **Строка состояния** — ARMED/DISARMED, режим полёта (название по типу аппарата: самолёт, коптер,
  наземный), GPS (тип фиксации и спутники), батарея (В, А, %), расстояние и пеленг на точку взлёта.
- **Авиагоризонт** — небо и земля по крену и тангажу, лестница тангажа через 5°, дуга крена
  (10/20/30/45/60°), символ самолёта. Ориентация сглаживается между пакетами (Tween 120 мс).
- **Лента скорости** (слева, путевая) с воздушной числом, **лента высоты** (справа, над точкой взлёта)
  с вариометром, **лента курса** (снизу) с меткой трека (розовая) и направления на дом (зелёная).
- **Под прибором** — координаты, высота над уровнем моря, давление, температура.
- **Нет данных** — если пакеты не приходили дольше `limits.staleMs` (по умолчанию 2 с), прибор
  перечёркивается и помечается «НЕТ ДАННЫХ»; в шапке всегда виден возраст данных.
- **Узкая ячейка** (уже 440 px) — ленты скорости и высоты заменяются числами поверх горизонта.

## Пропсы

| Название         | Тип                                             | По умолчанию                     | Описание                                                      |
| ---------------- | ----------------------------------------------- | -------------------------------- | ------------------------------------------------------------- |
| `id`             | `string`                                        | `undefined`                      | Префикс группы полей (`"MAV"`), используется вызывающим кодом |
| `wrapperClass`   | `string`                                        | `""`                             | CSS-классы обёртки                                            |
| `componentClass` | `string`                                        | `""`                             | «Мастер-цвет» виджета — роль вида `"bg-red"`                  |
| `label`          | `{ name?: string }`                             | `{ name: "Пилотажный дисплей" }` | Заголовок карточки                                            |
| `value`          | `Partial<IWidgetPFDData>`                       | `undefined`                      | Поля группы; без них — «НЕТ ДАННЫХ»                           |
| `keys`           | `Partial<Record<keyof IWidgetPFDData, string>>` | `undefined`                      | Переопределение имён полей устройства                         |
| `limits`         | `IWidgetPFDLimits`                              | `undefined`                      | Границы цветовых зон, см. ниже                                |
| `collapsed`      | `boolean`                                       | `false`                          | Свёрнуто ли тело виджета (`$bindable`)                        |
| `persistKey`     | `string`                                        | `undefined`                      | Ключ для сохранения `collapsed` в `localStorage`              |

### IWidgetPFDLimits

| Поле       | Описание                                                     |
| ---------- | ------------------------------------------------------------ |
| `speedMin` | м/с — ниже красная зона на ленте скорости                    |
| `speedMax` | м/с — выше красная зона                                      |
| `bankMax`  | ° — за пределом дуга крена красная, указатель крена краснеет |
| `altMax`   | м — выше красная зона на ленте высоты                        |
| `battLow`  | % — ниже батарея в строке состояния красная                  |
| `staleMs`  | мс без новых данных до флага «НЕТ ДАННЫХ», по умолчанию 2000 |

Незаданная граница не рисуется.

## Примеры

```svelte
<UI.WidgetPFD value={mav} limits={{ speedMin: 8, speedMax: 25, bankMax: 30, altMax: 150, battLow: 20 }} />
```

## Конструктор свойств (WidgetPFDProps.svelte)

Группы панели: общие (заголовок, группа полей, мастер-цвет), границы.

### Что настраивается

- Префикс группы (ID), мастер-цвет
- Границы: мин./макс. скорость и макс. высота — красные зоны на лентах; предельный крен — красная дуга; низкий заряд; время до «НЕТ ДАННЫХ»
