# WidgetPFD Component

## Назначение

Пилотажный дисплей (PFD) — главный прибор контроля полёта: пространственное положение, скорость, высота, курс и состояние систем.

> **Размеры.** Ширина — 100% контейнера (в конструкторе — ширина ячейки сетки), без собственного ограничения; высота — по содержимому, в сетке конструктора виджет занимает одну строку. Мастер-цвет (`componentClass`) перекрашивает шапку и рамки значений.

## Пакет данных

- Поля группы `MAV` — телеметрия автопилота MAVLink (меняется префиксом в настройках), привязывать переменные не нужно
- Поток телеметрии: `Roll`, `Pitch`, `Heading` — ~20 раз в секунду, остальное — 1–2 раза в секунду
- Только отображение, ничего не отправляет

## Ключи

| Ключ                      | Описание                                                                                                                                                     |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Roll`, `Pitch`           | числа, °: крен (вправо +) и тангаж (вверх +)                                                                                                                 |
| `Heading`                 | число, 0–360°: курс                                                                                                                                          |
| `GSpeed`, `ASpeed`        | числа, м/с: путевая и воздушная скорость                                                                                                                     |
| `Alt`                     | число, м: высота над точкой взлёта; `AltMSL` — над уровнем моря                                                                                              |
| `Climb`                   | число, м/с: вертикальная скорость (вверх +)                                                                                                                  |
| `Lat`, `Lon`              | числа, °: координаты                                                                                                                                         |
| `Vx`, `Vy`                | числа, м/с: скорость на север и восток — для трека                                                                                                           |
| `Fix`                     | число: тип фиксации GPS, `0`–`1` нет, `2` 2D, `3` 3D, `4`–`6` DGPS/RTK; `Sat` — число спутников                                                              |
| `BV`                      | В; `BC` — А (`-1` не измеряется); `BRem` — % (`-1` неизвестно)                                                                                               |
| `Mode`                    | число: режим автопилота; `VType` — тип аппарата (по нему — названия режимов); `Armed` — `1` взведён                                                          |
| `HomeLat`, `HomeLon`      | числа, °: точка взлёта, `0` — неизвестна                                                                                                                     |
| `Press`                   | гПа, `Temp` — °C                                                                                                                                             |
| `WPNum`                   | число: номер текущей точки маршрута; `0` — маршрута нет, метки целей не рисуются                                                                             |
| `WPDist`, `WPBrg`         | числа: расстояние до точки, м; курс на неё, 0–360° — бирюзовый ◆ на ленте курса                                                                              |
| `AltErr`, `SpdErr`        | числа: цель минус текущее — высота, м, и воздушная скорость, м/с; бирюзовые метки на лентах                                                                  |
| `XTE`                     | число, м: боковое отклонение от линии маршрута                                                                                                               |
| `RSSI`, `RemRSSI`         | числа, %: уровень сигнала своей и удалённой стороны; `-1` — неизвестно                                                                                       |
| `Drop`                    | число, %: потери пакетов телеметрии                                                                                                                          |
| `HDOP`                    | число: точность GPS по горизонтали (до 1 — отлично, больше 2 — неточно); `-1` — неизвестно                                                                   |
| `EKF`                     | число: наибольшая дисперсия навигационного фильтра; от `0.5` — внимание, от `0.8` — тревога (индикатор «НАВ»)                                                |
| `SensErr`                 | число: включённых, но неисправных датчиков; больше 0 — «НАВ» красный                                                                                         |
| `Msg`, `MsgSev`, `MsgSeq` | сообщение автопилота (строка), важность MAV_SEVERITY (`0`–`3` ошибка, `4` предупреждение, `5`–`7` информация), номер — новое сообщение даже с тем же текстом |

## Особенности

Смарт-виджет «Пилотажный дисплей» (Primary Flight Display) — главный прибор контроля полёта, как в стеклянной кабине самолёта или наземной станции управления. Работает с полями группы (по умолчанию `MAV`) ровно в том виде, в каком их отдаёт телеметрия автопилота MAVLink устройства 20.00.000-01. Только отображение: ничего не отправляет и не знает про DeviceStore/WebSocket.

- **Строка состояния** — группы «Система» (ARMED/DISARMED, режим по типу аппарата, индикатор «НАВ» по дисперсии EKF и неисправным датчикам), «GPS» (фиксация, спутники, HDOP), «Связь» (сигнал своей/удалённой стороны, потери пакетов), «Батарея» (В, А, %).
- **Авиагоризонт** — небо и земля по крену и тангажу, лестница тангажа через 5°, дуга крена (10/20/30/45/60°), символ самолёта. Ориентация сглаживается между пакетами (Tween 120 мс).
- **Лента скорости** (слева, путевая над землёй) и **лента высоты** (справа, над точкой взлёта) с вариометром у края, **лента курса** (снизу): розовый ▲ — трек (куда аппарат реально движется, по `Vx`/`Vy`), зелёный ● — направление на точку взлёта.
- **Углы под лентами** — воздушная скорость `AS m/s` (относительно воздуха, отличается от путевой на ветер) и вертикальная скорость `VS m/s` (+ набор зелёным, − снижение оранжевым).
- **Подсказки** — наведите курсор на любой элемент прибора, строки состояния или значений: расшифровка появляется в информационной строке внизу горизонта: первая строка — величина, единица и текущее значение (обновляется, пока курсор стоит на месте), ниже по строке — что означают знаки, цвета и пороги. Элемент помечен `data-tip` с ключом, тексты собраны в `tips` в скрипте виджета, поэтому её не обрезают края и прокрутка. Без наведения в той же строке — последнее сообщение автопилота (10 с), наведение на неё показывает историю. Включаются и выключаются кнопкой «?» в шапке; выбор общий для всех PFD в браузере (`hintsSetting("WidgetPFD")` из `hints.ts`, ключ `localStorage` `WidgetHints.WidgetPFD`, по умолчанию выключены; прежний выбор `WidgetPFD.tips` переносится).
- **Под прибором** — группы «Маршрут» (точка, расстояние, боковое отклонение), «Дом» (расстояние и направление), «Трек», «Позиция» (координаты, MSL), «Воздух» (давление, температура); каждая величина показана один раз.
- **Метки целей** (бирюзовые) — целевая скорость и высота текущей точки на лентах, курс на точку ◆ на ленте курса; цель за пределами ленты прижимается к краю.
- **Сообщения автопилота** (`STATUSTEXT`) — в информационной строке внизу горизонта на 10 с, цвет по важности; история последних пяти — при наведении на строку.
- **Нет данных** — если пакеты не приходили дольше `limits.staleMs` (по умолчанию 2 с), прибор перечёркивается и помечается «NO DATA»; в шапке всегда виден возраст данных.
- **Узкая ячейка** (уже 440 px) — ленты скорости и высоты заменяются числами поверх горизонта: путевая скорость, м/с, и высота, м, с вертикальной скоростью, м/с.

## Пропсы

| Название         | Тип                                             | По умолчанию | Описание                                                           |
| ---------------- | ----------------------------------------------- | ------------ | ------------------------------------------------------------------ |
| `id`             | `string`                                        | `undefined`  | Префикс группы полей (`"MAV"`), используется вызывающим кодом      |
| `wrapperClass`   | `string`                                        | `""`         | CSS-классы обёртки                                                 |
| `componentClass` | `string`                                        | `""`         | «Мастер-цвет» виджета — роль вида `"bg-red"`                       |
| `label`          | `{ name?: string }`                             | `{}`         | Заголовок карточки; пустой — «Пилотажный дисплей» на текущем языке |
| `value`          | `Partial<IWidgetPFDData>`                       | `undefined`  | Поля группы; без них — «NO DATA»                                   |
| `keys`           | `Partial<Record<keyof IWidgetPFDData, string>>` | `undefined`  | Переопределение имён полей устройства                              |
| `limits`         | `IWidgetPFDLimits`                              | `undefined`  | Границы цветовых зон, см. ниже                                     |
| `collapsed`      | `boolean`                                       | `false`      | Свёрнуто ли тело виджета (`$bindable`)                             |
| `persistKey`     | `string`                                        | `undefined`  | Ключ для сохранения `collapsed` в `localStorage`                   |

### IWidgetPFDLimits

| Поле       | Описание                                                     |
| ---------- | ------------------------------------------------------------ |
| `speedMin` | м/с — ниже красная зона на ленте скорости                    |
| `speedMax` | м/с — выше красная зона                                      |
| `bankMax`  | ° — за пределом дуга крена красная, указатель крена краснеет |
| `altMax`   | м — выше красная зона на ленте высоты                        |
| `battLow`  | % — ниже батарея в строке состояния красная                  |
| `staleMs`  | мс без новых данных до флага «NO DATA», по умолчанию 2000    |

Незаданная граница не рисуется.

## Примеры

```svelte
<UI.WidgetPFD value={mav} limits={{ speedMin: 8, speedMax: 25, bankMax: 30, altMax: 150, battLow: 20 }} />
```

## Конструктор свойств (WidgetPFDProps.svelte)

Группы панели: общие (заголовок, группа полей, мастер-цвет), границы.

### Что настраивается

- Префикс группы (ID), мастер-цвет
- Границы: мин./макс. скорость и макс. высота — красные зоны на лентах; предельный крен — красная дуга; низкий заряд; время до «NO DATA»
