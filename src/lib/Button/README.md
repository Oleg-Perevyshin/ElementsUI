# Button

Кнопка. В интерфейсе устройства по нажатию отправляет команду, например перезагрузку или сохранение настроек.

## Назначение

Отправляет команду на устройство по нажатию.

## Пакет данных

- По нажатию уходит **Заголовок** и **Аргумент**, например `SET` и `Restart`.
- **Переменные.** Текущие значения других компонентов кладутся в тот же пакет. Так делается кнопка «Сохранить» для полей с аргументом `NoSend`.
- **Фиксированное значение** (JSON) отправляется как есть вместо переменных, например `{"Mode": 2}`.
- Значение с устройства кнопка не показывает.

## Ключи

| Ключ | Описание |
|---|---|
| `<переменные>` | Имена через пробел, например `CFG.StaSSID CFG.StaPSK`. В имени переменной пробелов нет |

## Особенности

- Вид кнопки задаёт класс `bg-*` в `componentClass`. Синий, зелёный и другие яркие цвета дают залитую кнопку с белым текстом, красный и розовый дают кнопку опасного действия, `bg-max`, `bg-gray` и мягкие оттенки дают кнопку с контуром. Без `bg-*` или с `bg-transparent` кнопка выглядит как текст акцентного цвета.
- Кнопка с иконкой и без текста круглая.
- Горячая клавиша (`keyBind`) слушается на всём окне. Две кнопки с одной клавишей сработают обе.
- Подсказка `content.info` показывает только текст, без разметки.

## Пропсы

| Название | Тип | По умолчанию | Описание |
|---|---|---|---|
| `id` | `string` | `crypto.randomUUID()` | Идентификатор |
| `wrapperClass` | `string` | `""` | Классы обёртки |
| `componentClass` | `string` | `""` | Классы самой кнопки, здесь задают `bg-*` |
| `disabled` | `boolean` | `false` | Кнопка неактивна |
| `content.name` | `string` | | Текст |
| `content.icon` | `Component \| string \| null` | `null` | Иконка: Svelte-компонент или SVG-строка |
| `content.info` | `{ text, side }` | | Подсказка при наведении. `side`: `top`, `bottom`, `left`, `right` |
| `keyBind` | `object` | `{ showHint: true }` | Горячая клавиша: `key`, `ctrlKey`, `shiftKey`, `altKey`, `metaKey` |
| `keyBind.showHint` | `boolean` | `true` | Показывать клавишу на кнопке |
| `onClick` | `() => void` | | Нажатие кнопкой мыши или горячей клавишей |

## Примеры

```svelte
<script>
  import * as UI from "poe-svelte-ui-lib"
</script>

<UI.Button content={{ name: "Сохранить" }} componentClass="bg-blue" onClick={() => console.log("сохранено")} />

<UI.Button content={{ name: "Удалить" }} componentClass="bg-red" disabled />

<UI.Button content={{ name: "Обновить", info: { text: "Ctrl+R", side: "bottom" } }} keyBind={{ key: "r", ctrlKey: true }} onClick={refresh} />

<UI.Button content={{ icon: IconSettings }} onClick={openSettings} />
```

## Панель свойств (ButtonProps.svelte)

Панель для конструктора DevCloud. В ней задают текст, иконку из библиотеки иконок, цвет, подсказку, заголовок и аргумент команды, переменные или фиксированное значение.

| Пропс | Тип | Описание |
|---|---|---|
| `component` | `UIComponent & { properties: Partial<IButtonProps> }` | Компонент и его свойства |
| `onPropertyChange` | `(updates) => void` | Сообщает об изменении свойств |
| `forConstructor` | `boolean` | `true` - полная панель конструктора, `false` - упрощённая для редактирования |
