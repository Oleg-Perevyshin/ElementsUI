# WidgetWiFi

Смарт-виджет настройки сети устройства: режим WiFi, подключение к роутеру, своя точка доступа. Работает сразу со всеми полями сети, привязывать переменные по одной не нужно.

## Назначение

Полная настройка сети устройства: режим, подключение к роутеру, своя точка доступа.

Ширина виджета равна ширине контейнера, высота по содержимому. В сетке конструктора он занимает одну строку.

## Пакет данных

- Работает с полями группы `CFG`. Группу можно сменить префиксом в настройках.
- Поля правятся на месте. Кнопка «Сохранить» отправляет изменённые поля одним пакетом `SET ModCfg`.
- Кнопка поиска (лупа) отправляет `GET APsList`. Найденные сети появляются в списке у поля SSID.

## Ключи

| Ключ                      | Описание                                                    |
| ------------------------- | ----------------------------------------------------------- |
| `WiFiMode`                | Режим: `0` выключен, `1` клиент, `2` точка доступа, `3` оба |
| `StaSSID`, `StaPSK`       | Сеть роутера и её пароль                                    |
| `StaticIP`                | `0` DHCP, `1` статический адрес                             |
| `StaIP`, `StaMS`, `StaGW` | Адрес, маска и шлюз в сети роутера                          |
| `ApSSID`, `ApPSK`         | Имя и пароль своей точки доступа                            |
| `ApIP`, `ApMS`, `ApGW`    | Адрес, маска и шлюз своей точки доступа                     |

## Особенности

- Набор полей зависит от режима. В режиме клиента видны SSID и пароль роутера в одну строку, переключатель DHCP или статический адрес и поля адреса. В режиме точки доступа видны её имя, пароль и адреса.
- При выборе сети из списка в SSID попадает только имя сети, без уровня сигнала и канала.
- Пароль либо пустой, либо от 8 до 63 символов. Адреса проверяются как IPv4. SSID не длиннее 32 символов.
- Браузер не подставляет в поля сохранённые логины: у пароля `autocomplete="one-time-code"`.
- Переход в режим «только точка доступа» отключает подключение к роутеру. Поэтому при сохранении такого режима появляется предупреждение (`confirmOnAP`). На само переключение режима предупреждения нет.
- Мастер-цвет (`componentClass`) красит значок, переключатели, рамку фокуса и шапку таблиц в виджете.
- Шапка сворачивает виджет. Свёрнутое состояние по умолчанию задаётся в конструкторе (`collapsed`), а с `persistKey` личный выбор пользователя запоминается в браузере.
- Кнопка «?» в шапке включает подсказки к неочевидным полям. Выбор запоминается в браузере для каждого виджета отдельно, по его `persistKey`. Без `persistKey` выбор общий для всех виджетов этого типа.
- Сам виджет с устройством не говорит. Читает и пишет поля приложение (`GUIPreview.svelte` в облаке и WebApp).

## Пропсы

| Название         | Тип                                    | По умолчанию     | Описание                                          |
| ---------------- | -------------------------------------- | ---------------- | ------------------------------------------------- |
| `id`             | `string`                               | `"CFG"`          | Префикс группы полей                              |
| `keys`           | `Partial<Record<ключ, string>>`        | имена ключей     | Другие имена полей, если у прошивки иначе         |
| `value`          | `IWidgetWiFiConfig`                    |                  | Текущие значения полей                            |
| `label.name`     | `string`                               | `"WiFi"`         | Заголовок. Пусто - название на языке пользователя |
| `wrapperClass`   | `string`                               | `""`             | Классы обёртки                                    |
| `componentClass` | `string`                               | `""`             | Мастер-цвет `bg-*`                                |
| `allowedModes`   | `number[]`                             | `[1, 2, 3]`      | Какие режимы можно выбрать                        |
| `confirmOnAP`    | `boolean`                              | `true`           | Предупреждать при сохранении режима точки доступа |
| `scanCommand`    | `{ header, argument }`                 | `GET`, `APsList` | Команда поиска сетей                              |
| `collapsed`      | `boolean`                              | `false`          | Свёрнут ли. Можно связать через `bind:collapsed`  |
| `persistKey`     | `string`                               |                  | Ключ для запоминания свёрнутого состояния         |
| `onScan`         | `() => Promise<{ id, name, value }[]>` |                  | Найти сети. `name` подпись в списке, `value` SSID |
| `onSave`         | `(config) => void`                     |                  | Нажата «Сохранить», в `config` изменённые поля    |

## Пример

```svelte
<script>
  import * as UI from "poe-svelte-ui-lib"

  const scan = async () => [{ id: "1", name: "Home (-48 dBm, ch 6)", value: "Home" }]
  const save = (config) => sendModCfg(config)
</script>

<UI.WidgetWiFi value={wifi} onScan={scan} onSave={save} />
```

## Панель свойств (WidgetWiFiProps.svelte)

В конструкторе задают заголовок, префикс группы, другие имена полей, разрешённые режимы, предупреждение при режиме точки доступа и мастер-цвет.
