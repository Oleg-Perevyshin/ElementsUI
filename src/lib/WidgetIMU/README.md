# 🧊 WidgetIMU

Показания IMU и калибровка нуля. Ускорения, угловые скорости и температура видны крупными надписями, а не полями ввода. Виджет подходит к любому IMU, у которого в прошивке тот же договор ключей.

## ✨ Что умеет

- 📏 Показывает ускорение по осям и его модуль. В покое модуль около 1 g.
- 🌀 Показывает угловую скорость по осям. В покое она около нуля.
- 🌡️ Показывает температуру чипа.
- 🚦 Показывает режим датчика: стоп, измеряет или калибровка.
- 🎯 Кнопкой «Калибровать» запускает калибровку нуля гироскопа и подсказывает, что делать с датчиком.
- 📐 Если прошивка умеет, показывает блок «Акселерометр: 6 положений»: точная калибровка смещения и масштаба каждой оси, записанные положения подсвечены.
- ⏳ Пока идёт калибровка, показывает полосу времени, а потом сам перечитывает настройки датчика.
- ⚙️ Если выбрана микросхема, показывает раздел «Настройки датчика» (диапазоны, частоты данных, фильтры, питание акселерометра и гироскопа). Поля читаются из `Cfg` и сохраняются кнопкой «Сохранить», «По умолчанию» ставит заводские настройки чипа. У акселерометра и гироскопа первым в строке стоит «Режим»: «Выключен» прячет остальные настройки узла, экономичный режим есть только у акселерометра. Показаны только сочетания, допустимые по даташиту. Фильтр показан частотой среза в Гц, пересчитанной из частоты данных своего узла.
- 🔽 Сворачивается по клику на заголовок.
- ❓ Кнопка «?» в шапке включает подсказки.

## 🧩 Как настроить в конструкторе

1. Перетащите виджет на макет. Привязывать переменные не нужно.
2. Если нужно, задайте заголовок. Без него карточка называется «IMU».
3. Если в прошивке у IMU другая группа настроек, впишите её. По умолчанию это `IMUF`.
4. Выберите микросхему, например ICM-42688-P. Без неё виджет показывает только показания и калибровку.
5. Выберите мастер-цвет виджета.

## 💡 Полезно знать

- 🧘 Во время калибровки нуля гироскопа датчик лежит неподвижно, положение любое. Калибровка идёт около 3 секунд, если датчик двигали - не сохраняется.
- 🧭 Для калибровки по 6 положениям датчик по очереди ставят каждой осью вверх и вниз, порядок любой. После шестого положения калибровка сохраняется.
- 🔁 После калибровки датчик возвращается в прежний режим, смещения сохраняются в устройстве.
- 🔒 Первое поле настроек - «Режим работы»: стоп или измерять. Калибровку оно не запускает, это делает кнопка «Калибровать». Пока идёт калибровка или запись положения, настройки недоступны, а в режиме «Стоп» калибровать нельзя. Биты, которых нет в описании микросхемы, не трогаются.
- 🧩 Новая микросхема - новая запись `SENSOR_CHIPS` в `sensorChips.ts`, биты ровно как в структуре `Cfg` драйвера прошивки.
- 📐 Виджет занимает всю ширину своей ячейки, а высота подстраивается под содержимое.

<details>
<summary>📦 Договор с прошивкой</summary>

- Работает с полями группы `IMUF`. Группу можно сменить префиксом в настройках.
- Режим датчика - биты 0-1 слова `Cfg`: `0` стоп, `1` измерять, `2` ноль гироскопа, `3` записать положение акселерометра. Так у драйвера ICM42688 и должно быть у любого другого драйвера IMU.
- «Калибровать» отправляет `SET ModuleConfig {IMUF.Cfg: слово}`, где в битах 0-1 стоит `2`, а остальные биты как были. «Записать положение» отправляет то же слово с `3` в битах 0-1 и через 2.5 с зовёт `onRefresh`, чтобы получить новый `ACP`.
- Прошивка сама возвращается в прежний режим, но `Cfg` без запроса не присылает. Поэтому через `calibrateMs` (по умолчанию 4000 мс) виджет зовёт `onRefresh`, и приложение шлёт `GET ModuleConfig {CfgGroup: IMUF}`.
- Показания только читаются. Обычно они приходят потоком `OK! SystemDataStream`.

</details>

<details>
<summary>🔑 Ключи</summary>

| Ключ             | Описание                                                                                            |
| ---------------- | --------------------------------------------------------------------------------------------------- |
| `Cfg`            | Биты 0-1 - режим, остальные - настройки микросхемы                                                  |
| `ACP`            | Записанные положения калибровки по 6 положениям: биты +X, -X, +Y, -Y, +Z, -Z. Нет ключа - блока нет |
| `AX`, `AY`, `AZ` | Ускорение, g                                                                                        |
| `GX`, `GY`, `GZ` | Угловая скорость, °/с                                                                               |
| `T`              | Температура, °C                                                                                     |

</details>
