# 🧊 WidgetIMU

Показания IMU и калибровка нуля. Ускорения, угловые скорости и температура видны крупными надписями, а не полями ввода. Виджет подходит к любому IMU, у которого в прошивке тот же договор ключей.

## ✨ Что умеет

- 📏 Показывает ускорение по осям и его модуль. В покое модуль около 1 g.
- 🌀 Показывает угловую скорость по осям. В покое она около нуля.
- 🌡️ Показывает температуру чипа.
- 🚦 Показывает режим датчика: стоп, измеряет или калибровка.
- 🎯 Кнопкой «Калибровать» запускает калибровку нуля и подсказывает, что делать с датчиком.
- ⏳ Пока идёт калибровка, показывает полосу времени, а потом сам перечитывает настройки датчика.
- ⚙️ Если выбрана микросхема, показывает раздел «Настройки датчика» (диапазоны, частоты данных, фильтры, питание акселерометра и гироскопа). Поля читаются из `Cfg` и сохраняются кнопкой «Сохранить», «По умолчанию» ставит заводские настройки чипа.
- 🔽 Сворачивается по клику на заголовок.
- ❓ Кнопка «?» в шапке включает подсказки.

## 🧩 Как настроить в конструкторе

1. Перетащите виджет на макет. Привязывать переменные не нужно.
2. Если нужно, задайте заголовок. Без него карточка называется «IMU».
3. Если в прошивке у IMU другая группа настроек, впишите её. По умолчанию это `IMUF`.
4. Выберите микросхему, например ICM-42688-P. Без неё виджет показывает только показания и калибровку.
5. Выберите мастер-цвет виджета.

## 💡 Полезно знать

- 🧘 Во время калибровки датчик должен лежать неподвижно осью Z вверх. Калибровка идёт около 3 секунд.
- 🔁 После калибровки датчик сам снова начинает измерять, смещения сохраняются в устройстве.
- 🔒 Режим работы (биты 0-1 `Cfg`) в настройках не меняется: им управляет калибровка. Биты, которых нет в описании микросхемы, тоже не трогаются.
- 🧩 Новая микросхема - новая запись `SENSOR_CHIPS` в `sensorChips.ts`, биты ровно как в структуре `Cfg` драйвера прошивки.
- 📐 Виджет занимает всю ширину своей ячейки, а высота подстраивается под содержимое.

<details>
<summary>📦 Договор с прошивкой</summary>

- Работает с полями группы `IMUF`. Группу можно сменить префиксом в настройках.
- Режим датчика - биты 0-1 слова `Cfg`: `0` стоп, `1` измерять, `2` калибровать. Так у драйвера ICM42688 и должно быть у любого другого драйвера IMU.
- «Калибровать» отправляет `SET ModuleConfig {IMUF.Cfg: слово}`, где в битах 0-1 стоит `2`, а остальные биты как были.
- Прошивка сама возвращается в измерение, но `Cfg` без запроса не присылает. Поэтому через `calibrateMs` (по умолчанию 4000 мс) виджет зовёт `onRefresh`, и приложение шлёт `GET ModuleConfig {CfgGroup: IMUF}`.
- Показания только читаются. Обычно они приходят потоком `OK! SystemDataStream`.

</details>

<summary>🔑 Ключи</summary>

| Ключ             | Описание                                           |
| ---------------- | -------------------------------------------------- |
| `Cfg`            | Биты 0-1 - режим, остальные - настройки микросхемы |
| `AX`, `AY`, `AZ` | Ускорение, g                                       |
| `GX`, `GY`, `GZ` | Угловая скорость, °/с                              |
| `T`              | Температура, °C                                    |
