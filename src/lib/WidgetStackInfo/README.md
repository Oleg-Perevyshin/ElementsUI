# WidgetStackInfo Component

## Назначение

Отладка прошивки: свободная память и запас стека задач.

> **Размеры.** Ширина — 100% контейнера (в конструкторе — ширина ячейки сетки), без собственного ограничения; высота — по содержимому, в сетке конструктора виджет занимает одну строку. Мастер-цвет (`componentClass`) перекрашивает и шапку таблиц внутри виджета (`--table-header-color`).

## Пакет данных

- Один объект `StackInfo` из ответа на `GET StackInfo`, привязывать переменные не нужно
- Запрос — кнопкой «Обновить» или автоопросом

### Протокол устройства

```
"StackInfo": {
  "Heap": [
    { "Name": "Internal", "Total": 327680,  "Free": 118000,  "MinFree": 92000 },
    { "Name": "PSRAM",    "Total": 4194304, "Free": 3980000, "MinFree": 3920000 }
  ],
  "Tasks": [{ "Name": "api_task", "FreeMin": 1240, "Prio": 5, "Core": 1, "State": 2 }]
}
```

Коды куч виджет показывает понятными подписями на языке пользователя — «Встроенная ОЗУ», «Внешняя ОЗУ (PSRAM)», «ОЗУ» (`Heap` у STM) — с подсказкой при наведении, что это за память и чем опасна нехватка; неизвестный код — как пришёл. Все размеры в байтах. ESP отдаёт непересекающиеся кучи `Internal` (встроенная ОЗУ) и `PSRAM` (внешняя, только если есть на устройстве) и `Core` (-1 — без привязки к ядру); STM — одну кучу `Heap` (heap_4, `configTOTAL_HEAP_SIZE`) и без `Core`. `State` — `eTaskState`: 0 работает, 1 готова, 2 ожидает, 3 приостановлена, 4 удалена.

## Ключи

| Ключ    | Описание                                                                                                                                                                                                                                        |
| ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Heap`  | массив `[{ "Name", "Total", "Free", "MinFree" }]`, байт: кучи памяти, `MinFree` — минимум свободного с момента старта                                                                                                                           |
| `Tasks` | массив `[{ "Name", "State", "Prio", "Core", "FreeMin" }]`: задачи; `State` — `0` выполняется, `1` готова, `2` ждёт, `3` приостановлена, `4` удалена; `Core` — ядро (только ESP32, `-1` без привязки); `FreeMin` — минимальный запас стека, байт |

## Особенности

Отладочный смарт-виджет памяти и задач FreeRTOS: занятость каждой кучи и минимальный запас стека каждой задачи. Работает с одним объектом `StackInfo` ровно в том виде, в каком его отдаёт `API_GetStackInfo` (ProdFactory-ESP и ProdFactory-STM — контракт общий), и с одним запросом `GET StackInfo`. Компонент ничего не знает про DeviceStore/WebSocket — только `value` и `onRefresh`.

- **Кучи** — карточка на каждую: «занято X из Y», процент (оранжевый от 75%, красный от 90%) и полоса мастер-цвета; светлая подложка полосы — пик занятости с момента старта (`Total − MinFree`).
- **Задачи** — таблица «Задача / Состояние / Приоритет / Ядро / Запас». Порядок всегда по возрастанию запаса стека: самые рискованные сверху (сортировка кликом при автоопросе сбрасывалась бы на каждом ответе). Запас меньше `warnBytes` — красный, меньше удвоенного — оранжевый, над таблицей — число задач ниже порога. Колонка «Ядро» есть, только если устройство передаёт `Core`.
- **Обновление** — кнопка «Обновить» и автоопрос «Выкл / 1 с / 5 с / 10 с» (`period`); при включении опрос сразу шлёт запрос, свёрнутый виджет не опрашивает.

## Пропсы

| Название         | Тип                      | По умолчанию | Описание                                                                  |
| ---------------- | ------------------------ | ------------ | ------------------------------------------------------------------------- |
| `wrapperClass`   | `string`                 | `""`         | CSS-классы обёртки                                                        |
| `componentClass` | `string`                 | `""`         | «Мастер-цвет» виджета — роль вида `"bg-red"`, перекрашивает весь виджет   |
| `label`          | `{ name?: string }`      | `{}`         | Заголовок карточки; пустой — «Память и задачи» на текущем языке           |
| `value`          | `IWidgetStackInfo`       | `undefined`  | Снимок `StackInfo`; без него — «Нет данных»                               |
| `keys`           | `{ StackInfo?: string }` | `undefined`  | Переопределение имени объекта ответа, по умолчанию `StackInfo`            |
| `argument`       | `string`                 | `undefined`  | Аргумент запроса, по умолчанию `"StackInfo"` (используется вызывающим)    |
| `warnBytes`      | `number`                 | `512`        | Порог подсветки запаса стека, байт                                        |
| `period`         | `number`                 | `0`          | Период автоопроса, мс; 0 — только по кнопке (`$bindable`)                 |
| `collapsed`      | `boolean`                | `false`      | Свёрнуто ли тело виджета (`$bindable`)                                    |
| `persistKey`     | `string`                 | `undefined`  | Ключ для сохранения `collapsed` в `localStorage`                          |
| `onRefresh`      | `() => void`             | `undefined`  | Запрос снимка (`GET StackInfo`); без обработчика кнопка и опрос неактивны |

## Примеры

```svelte
<script>
  import * as UI from "poe-svelte-ui-lib"

  let stackInfo = $state()
</script>

<UI.WidgetStackInfo value={stackInfo} warnBytes={768} onRefresh={() => console.log("GET StackInfo")} />
```

## Конструктор свойств (WidgetStackInfoProps.svelte)

| Название           | Тип                                                                                             | Описание                                  |
| ------------------ | ----------------------------------------------------------------------------------------------- | ----------------------------------------- |
| `component`        | `UIComponent & { properties: Partial<IWidgetStackInfoProps> }`                                  | Объект компонента с его свойствами        |
| `onPropertyChange` | `(updates: Partial<{ properties?: string \| object; name?: string; access?: string }>) => void` | Коллбэк для обновления свойств компонента |

Группы панели: общие (заголовок, мастер-цвет), отображение (`warnBytes`, `period`), устройство (объект ответа, аргумент запроса).

### Что настраивается

- Порог запаса стека: меньше порога — красным, меньше удвоенного — оранжевым
- Автоопрос: выкл / 1 / 5 / 10 с; мастер-цвет

### Подсказки

Кнопка «?» в правом краю шапки включает и выключает подсказки этого виджета; выбор общий для всех `WidgetStackInfo` в браузере (`hintsSetting("WidgetStackInfo")`, `hints.ts`). Подсказка всплывает при наведении на поле, смысл которого не очевиден, — что это за значение и на что влияет.
