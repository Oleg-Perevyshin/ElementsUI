# WidgetStackInfo

Смарт-виджет для отладки прошивки: сколько свободной памяти и какой запас стека у каждой задачи FreeRTOS. Помогает поймать нехватку памяти до того, как устройство начнёт перезагружаться.

## Назначение

Отладка прошивки: свободная память и запас стека задач.

Ширина виджета равна ширине контейнера, высота по содержимому. В сетке конструктора он занимает одну строку.

## Пакет данных

- Работает с объектом `StackInfo` из ответа на `GET StackInfo`.
- Запрос отправляется кнопкой «Обновить» или автоопросом.

## Ключи

| Ключ | Описание |
|---|---|
| `Heap` | Кучи памяти `[{ "Name", "Total", "Free", "MinFree" }]`, байт. `MinFree` это наименьший свободный объём с момента запуска |
| `Tasks` | Задачи `[{ "Name", "State", "Prio", "Core", "CPU", "FreeMin" }]` |

Поля задачи:

| Поле | Что значит |
|---|---|
| `State` | `0` выполняется, `1` готова, `2` ждёт, `3` приостановлена, `4` удалена |
| `Prio` | Приоритет |
| `Core` | Ядро, только у ESP32. `-1` значит любое |
| `CPU` | Загрузка ядра задачей в процентах с прошлого ответа |
| `FreeMin` | Наименьший запас стека, байт |

## Протокол устройства

```
"StackInfo": {
  "Heap": [
    { "Name": "Internal", "Total": 327680, "Free": 118000, "MinFree": 92000 },
    { "Name": "PSRAM", "Total": 4194304, "Free": 3980000, "MinFree": 3920000 }
  ],
  "Tasks": [{ "Name": "api_rx_task", "FreeMin": 1240, "Prio": 5, "Core": 1, "State": 2, "CPU": 3.5 }]
}
```

Формат общий у ProdFactory-ESP и ProdFactory-STM, его отдаёт `API_GetStackInfo`. Все размеры в байтах.

## Особенности

- **Кучи.** Карточка на каждую: «занято X из Y», процент и полоса. Процент оранжевый от 75%, красный от 90%. Светлая подложка полосы показывает пик занятости с момента запуска (`Total − MinFree`).
- Имена куч переводятся на язык пользователя: `Internal` «Встроенная ОЗУ», `PSRAM` «Внешняя ОЗУ (PSRAM)», `Heap` (у STM) «ОЗУ». В подсказке объяснено, что это за память. Неизвестное имя выводится как есть.
- **Задачи.** Таблица «Задача, Состояние, Приоритет, Ядро, Запас». Задачи всегда идут по возрастанию запаса стека, самые рискованные сверху. Запас меньше `warnBytes` красный, меньше двойного `warnBytes` оранжевый.
- **Обновление.** Кнопка «Обновить» и автоопрос: выключен, 1, 5 или 10 секунд. Включённый автоопрос сразу отправляет запрос. Свёрнутый виджет не опрашивает устройство.
- Без данных виджет показывает «Нет данных».
- Сворачивание, мастер-цвет и кнопка «?» с подсказками работают как у `WidgetWiFi`.

## Пропсы

| Название | Тип | По умолчанию | Описание |
|---|---|---|---|
| `id` | `string` | | Префикс группы |
| `keys.StackInfo` | `string` | `"StackInfo"` | Имя объекта в ответе |
| `argument` | `string` | `"StackInfo"` | Аргумент запроса |
| `value` | `IWidgetStackInfo` | | Снимок `StackInfo` |
| `label.name` | `string` | | Заголовок. Пусто — «Стек и задачи» на языке пользователя |
| `wrapperClass` | `string` | `""` | Классы обёртки |
| `componentClass` | `string` | `""` | Мастер-цвет `bg-*` |
| `warnBytes` | `number` | `512` | Порог подсветки запаса стека, байт |
| `period` | `number` | `0` | Период автоопроса, мс. `0` только по кнопке. Можно связать через `bind:period` |
| `collapsed` | `boolean` | `false` | Свёрнут ли |
| `persistKey` | `string` | | Ключ для запоминания свёрнутого состояния |
| `onRefresh` | `() => void` | | Запросить снимок. Без него кнопка и автоопрос неактивны |

## Пример

```svelte
<UI.WidgetStackInfo value={stackInfo} warnBytes={1024} onRefresh={() => send("GET", "StackInfo")} />
```

## Панель свойств (WidgetStackInfoProps.svelte)

В конструкторе задают заголовок, порог подсветки, имя объекта, аргумент запроса и мастер-цвет.
