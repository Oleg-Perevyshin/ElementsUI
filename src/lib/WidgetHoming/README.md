# 🧱 WidgetHoming

База оси привода: как ищется база, нашлась ли она, где края и где вал сейчас. Кнопками можно найти базу и вывести ось домой, ниже - настройки поиска.

## ✨ Что умеет

- 🔎 Кнопка «Найти базу» запускает выбранный способ поиска: по двум упорам, одной метке или датчикам.
- 🏠 Кнопка «Домой» отправляет отдельную команду движения в домашнюю точку. Для двух краёв дом - середина хода плюс смещение.
- 📏 Для двух краёв виджет показывает полосу хода, рабочую зону, дом и текущее положение оси. Для одного датчика видны его координата и состояние.
- 🚦 Показывает способ поиска и состояние: не искали, идёт поиск, база найдена или отказ с причиной текстом.
- ⏳ Пока идёт поиск, раз в секунду перечитывает настройки устройства и кончает ожидание по ответу прошивки.
- ⚙️ Раздел «Настройки поиска»: дом от центра, скорость, отступ от краёв и настройки выбранного способа. Сохраняются кнопкой «Сохранить».
- 🔽 Сворачивается по клику на заголовок.
- ❓ Кнопка «?» в шапке включает подсказки.

## 🧩 Как настроить в конструкторе

1. Перетащите «База оси» на холст.
2. В свойствах выберите режим и при необходимости смените префикс группы (по умолчанию `HOME`).
3. Виджет читает поля группы автоматически. Справка ⓘ рядом с пропсами перечисляет ключи и единицы для каждого режима.

## 💡 Полезно знать

- 🧭 Поворотная ось передаёт углы в градусах, линейная - координаты в миллиметрах.
- 🧩 Набор полей зависит от режима в пропсах. В режиме механических упоров `Type` сообщает, включён ли поиск по упорам.
- 🔒 Пока идёт поиск, кнопки и настройки недоступны, а привод не исполняет команды движения по шине.
- 📐 Виджет занимает всю ширину своей ячейки, а высота подстраивается под содержимое.

<details>
<summary>🔧 Для программиста</summary>

- Режим `mode` задаёт автор GUI: `rotary` (два механических упора, по умолчанию), `rotarySensor` (угловая метка), `linear` (один датчик), `linearSensors` (два датчика).
- Свойство `id` задаёт префикс группы, по умолчанию `HOME`. Например, положение оси приходит под ключом `HOME.Pos`.
- Центр, положение и отклонение показаны до сотых. Для поворотной оси центр считается по дуге от `Lo` до `Hi` с учётом перехода через 0°. Для линейной используется середина между координатами краёв. Через секунду после завершения поиска виджет ещё раз запрашивает положение.
- «Найти базу» вызывает `onSearch` (`SET MotionHome {Search: 1}`), «Домой» - `onHome` (`SET MotionHome {}`), «Сохранить» - `onSave` с настройками выбранного режима (`SET ModuleConfig`).
- Пока поиск идёт (`St = 1` или кнопка только что нажата), виджет раз в секунду зовёт `onRefresh`, приложение шлёт `GET ModuleConfig {CfgGroup: HOME}`. `searchMs` (по умолчанию 120000 мс) - предел ожидания.
- Причина отказа: коды поиска (2070, 2071, 2072, 9) - короткий текст без чисел, параметров у `Err` нет; прочие коды - `formatDeviceMessage(Err)` словаря сообщений.

| Ключ        | Доступ | Режим и назначение                                                                                                                                          |
| ----------- | ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `St`        | Чтение | состояние поиска. `0` не запускался, `1` идёт, `2` завершён успешно, `3` отказ.                                                                             |
| `Err`       | Чтение | код сообщения об отказе. `0` при отсутствии ошибки.                                                                                                         |
| `Found`     | Чтение | признак известной базы. `1` означает, что база найдена.                                                                                                     |
| `Pos`       | Чтение | текущее положение оси в градусах или миллиметрах.                                                                                                           |
| `Lo`        | Чтение | первый край угловой дуги или меньшая координата линейного хода. Используется при двух краях.                                                                |
| `Hi`        | Чтение | второй край угловой дуги или большая координата линейного хода. Угловая дуга идёт от `Lo` в сторону увеличения угла с переходом через 0° при необходимости. |
| `Sensor`    | Чтение | состояние единственного датчика. `0` свободен, `1` активен.                                                                                                 |
| `SensorPos` | Чтение | координата единственного датчика или угловой метки в градусах или миллиметрах.                                                                              |
| `Phase`     | Чтение | этап поиска по датчикам при `St = 1`. `1` поиск, `2` отъезд, `3` точный подход.                                                                             |
| `Type`      | Чтение | способ поиска в режиме механических упоров. `0` поиск отключён, `1` поиск по упорам.                                                                        |
| `Speed`     | Запись | скорость поиска в °/с или мм/с.                                                                                                                             |
| `Off`       | Запись | смещение дома от середины между двумя краями в градусах или миллиметрах.                                                                                    |
| `Marg`      | Запись | запас с каждой стороны рабочего хода в градусах или миллиметрах. Используется при двух краях.                                                               |
| `Dir`       | Запись | направление поиска датчика. `-1` к меньшим координатам, `+1` к большим. При двух датчиках определяет первый край.                                           |
| `Backoff`   | Запись | расстояние отъезда от датчика в градусах или миллиметрах.                                                                                                   |
| `FineSpeed` | Запись | скорость повторного подхода к датчику в °/с или мм/с.                                                                                                       |
| `Force`     | Запись | усилие поиска механических упоров в процентах.                                                                                                              |
| `Lag`       | Запись | отставание остановившегося вала от цели в градусах, при котором распознаётся механический упор.                                                             |

</details>

При поиске по датчику ось подходит к нему, отъезжает и фиксирует координату при повторном срабатывании на малой скорости. При активном датчике поиск одной метки начинается с отъезда. В режиме двух линейных датчиков ось повторяет цикл у каждого края и затем выходит домой.
