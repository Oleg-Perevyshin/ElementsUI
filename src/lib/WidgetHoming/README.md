# 🧱 WidgetHoming

База оси привода: как ищется база, нашлась ли она, где края и где вал сейчас. Кнопками можно найти базу и вывести ось домой, ниже - настройки поиска.

## ✨ Что умеет

- 🔎 Кнопка «Найти базу» запускает поиск: ось сама находит оба края и плавно выходит домой. Перед запуском виджет спрашивает подтверждение - ось будет двигаться.
- 🏠 Кнопка «Домой» плавно выводит ось домой: в центр между краями плюс смещение.
- 📏 Полоса показывает разрешённый ход от края до края, зону работы без отступов, дом и вал сейчас. Вал за краем - красный.
- 🚦 Показывает способ поиска и состояние: не искали, идёт поиск, база найдена или отказ с причиной текстом.
- ⏳ Пока идёт поиск, раз в секунду перечитывает настройки устройства и кончает ожидание по ответу прошивки.
- ⚙️ Раздел «Настройки поиска»: дом от центра, скорость, отступ от краёв и настройки выбранного способа. Сохраняются кнопкой «Сохранить».
- 🔽 Сворачивается по клику на заголовок.
- ❓ Кнопка «?» в шапке включает подсказки.

## 🧩 Как настроить в конструкторе

1. Перетащите «База оси» на холст.
2. В свойствах при необходимости смените группу (по умолчанию `HOME`).
3. Переменные привязывать не нужно: виджет сам берёт поля группы.

## 💡 Полезно знать

- 🧭 Края и положение вала - в углах датчика оси, °. Разрешённый ход идёт от края `Lo` в плюс до края `Hi`.
- 🧩 Поля настроек зависят от способа поиска (`Type`): у механических упоров есть ещё усилие при поиске и порог упора.
- 🔒 Пока идёт поиск, кнопки и настройки недоступны, а привод не исполняет команды движения по шине.
- 📐 Виджет занимает всю ширину своей ячейки, а высота подстраивается под содержимое.

<summary>🔧 Для программиста</summary>

- Работает с полями группы `HOME` компонента `homing` прошивки. Группу можно сменить префиксом в настройках.
- «Найти базу» зовёт `onSearch` (облако и терминал шлют `SET MotionHome {Search: 1}`), «Домой» - `onHome` (`SET MotionHome {}`), «Сохранить» - `onSave` с полями `Off`, `Speed`, `Marg` и ключами способа (`SET ModuleConfig`).
- Пока поиск идёт (`St = 1` или кнопка только что нажата), виджет раз в секунду зовёт `onRefresh`, приложение шлёт `GET ModuleConfig {CfgGroup: HOME}`. `searchMs` (по умолчанию 120000 мс) - предел ожидания.
- Причина отказа: коды поиска (2070, 2071, 2072, 9) - короткий текст без чисел, параметров у `Err` нет; прочие коды - `formatDeviceMessage(Err)` словаря сообщений.

| Ключ    | Что это                                                    |
| ------- | ---------------------------------------------------------- |
| `Type`  | Способ: `0` базы нет, `1` механические упоры               |
| `St`    | Состояние: `0` не искали, `1` идёт, `2` найдена, `3` отказ |
| `Err`   | Код отказа последнего поиска, `0` - нет                    |
| `Found` | База найдена                                               |
| `Lo`    | Край, от которого разрешённый ход идёт в плюс, ° датчика   |
| `Hi`    | Второй край, ° датчика                                     |
| `Pos`   | Вал сейчас, ° датчика                                      |
| `Off`   | Дом от центра между краями, °; без базы - угол дома        |
| `Speed` | Скорость поиска и выхода домой, °/с                        |
| `Marg`  | Отступ от краёв в работе, °                                |
| `Force` | Способ «упоры»: усилие мотора при поиске, % от полного     |
| `Lag`   | Способ «упоры»: порог упора, °                             |

</details>
