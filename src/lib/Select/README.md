# Select

Выбор одного значения из списка: режим работы, скорость порта, часовой пояс. Бывает выпадающим списком, рядом кнопок или полем с поиском.

## Назначение

Выбор одного значения из вариантов.

## Пакет данных

- Читает и пишет одну переменную с выбранным значением.
- Варианты задаются в настройках или приходят с устройства отдельной переменной `<имя>-S`. Так строится, например, список найденных WiFi-сетей.
- Отправка настраивается в событии: **Заголовок** (обычно `SET`) и **Аргумент** (обычно `ModCfg`). С `NoSend` значение сразу не уходит, его отправит другой компонент. **Переменные** добавляют в тот же пакет значения других компонентов.

## Ключи

| Ключ | Описание |
|---|---|
| `<переменная>` | Значение выбранного варианта (`value`). Для битового поля целое число, меняются биты с N по M |
| `<переменная>-S` | Необязательный список вариантов `[{ "id", "name", "value" }, ...]` |

## Особенности

Виды (`type`):

| Вид | Что это |
|---|---|
| `select` | Выпадающий список |
| `buttons` | Ряд кнопок. Удобен для 2-4 коротких вариантов. Только он умеет выбирать несколько вариантов (`multiSelect`) |
| `input` | Поле с поиском по названиям вариантов |

- Выпадающий список выносится в `body`, поэтому его не обрезает прокрутка родителя. Закрывается кликом снаружи.
- В виде `buttons` вариант с `icon` показывает иконку, а `name` уходит в подсказку. Так узкие панели не обрезают подписи.
- Вариант со своим цветом (`class` с `bg-*`) показывает цвет всегда, а выбранный отмечается рамкой. Так сделана палитра цветов в панелях свойств.
- `fitContent` делает кнопки одинаковыми по самой длинной подписи, без переноса текста. Подходит для шапок и переключателей режима.
- `bitMode` и `range` нужны только панели свойств, сам `Select` их не читает.

## Пропсы

| Название | Тип | По умолчанию | Описание |
|---|---|---|---|
| `id` | `string` | `crypto.randomUUID()` | Идентификатор |
| `type` | `"select" \| "buttons" \| "input"` | `"select"` | Вид |
| `options` | `IOption[]` | `[]` | Варианты |
| `value` | `IOption \| IOption[]` | | Выбранный вариант, массив при `multiSelect`. Можно связать через `bind:value` |
| `multiSelect` | `boolean` | `false` | Несколько вариантов, только для `buttons` |
| `fitContent` | `boolean` | `false` | Кнопки по ширине содержимого, только для `buttons` |
| `listHeight` | `string` | `"16rem"` | Наибольшая высота списка для `select` и `input` |
| `label.name`, `label.class` | `string` | `""` | Заголовок и его классы |
| `wrapperClass`, `componentClass` | `string` | `""` | Классы обёртки и поля |
| `disabled` | `boolean` | `false` | Неактивен |
| `onUpdate` | `(value) => void` | | Выбран другой вариант |

Вариант `IOption`:

| Поле | Тип | Описание |
|---|---|---|
| `id` | `string` | Идентификатор |
| `value` | любой | Значение |
| `name` | `string` | Подпись |
| `class` | `string` | Классы, `bg-*` задаёт цвет варианта |
| `icon` | `string` | SVG или короткая метка вроде `"XL"`, только для `buttons` |
| `disabled` | `boolean` | Нельзя выбрать |

## Примеры

```svelte
<script>
  import * as UI from "poe-svelte-ui-lib"
  const modes = [
    { id: "1", name: "Авто", value: 0 },
    { id: "2", name: "Ручной", value: 1 },
  ]
  let mode = $state(modes[0])
</script>

<UI.Select label={{ name: "Режим" }} options={modes} bind:value={mode} />

<UI.Select type="buttons" options={modes} bind:value={mode} />

<UI.Select type="input" label={{ name: "Часовой пояс" }} options={zones} />
```

## Панель свойств (SelectProps.svelte)

В конструкторе задают вид, варианты, битовое поле (`bitMode` и биты `range`) и событие отправки.
