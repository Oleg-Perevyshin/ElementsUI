# Joystick

Джойстик из кнопок для управления по двум или трём осям: движение, поворот камеры, наклон.

## Назначение

Управление по нескольким осям, например движением или поворотом камеры.

## Пакет данных

- Читает и пишет одну переменную со значениями всех осей.
- Значение отправляется при каждом нажатии.
- Отправка настраивается в событии: **Заголовок** (обычно `SET`) и **Аргумент** (обычно `ModCfg`). С `NoSend` значение сразу не уходит, его отправит другой компонент.

## Ключи

| Ключ | Описание |
|---|---|
| `<переменная>` | Массив чисел по осям в порядке настроек, например `[x, y, z]`. Последний элемент - состояние центральной кнопки (0 или 1) |

## Особенности

- Кнопки направлений меняют оси на шаг чувствительности. Шаг выбирается переключателем: 0.01, 0.1, 1, 10 или 100.
- Значение оси не выходит за `minNum` и `maxNum`.
- Осей две или три, по умолчанию Pitch, Yaw и Roll. Если у третьей оси пустое имя, боковые кнопки третьей оси прячутся.
- Центральная кнопка переключает свой флаг (последний элемент массива) между 0 и 1. Ей можно задать иконку.
- В режиме `readonly` джойстик показывает положение с устройства, но не управляет.
- Подстраивается под размер контейнера.

## Пропсы

| Название | Тип | По умолчанию | Описание |
|---|---|---|---|
| `id` | `string` | `crypto.randomUUID()` | Идентификатор |
| `wrapperClass` | `string` | `""` | Классы обёртки |
| `label.name`, `label.class` | `string` | `""` | Заголовок и его классы |
| `value` | `number[]` | `[0, 0, 0, 0]` | Значения осей и флаг центральной кнопки |
| `axes` | `{ name, minNum?, maxNum? }[]` | Pitch, Yaw, Roll | Оси. Пределы по умолчанию -360 и 360 |
| `buttonIcon` | `Component \| string` | | Иконка центральной кнопки |
| `readonly` | `boolean` | `false` | Только показ |
| `onUpdate` | `(value: number[]) => void` | | Значение изменилось |

## Пример

```svelte
<script>
  import * as UI from "poe-svelte-ui-lib"
  let pos = $state([0, 0, 0, 0])
</script>

<UI.Joystick
  label={{ name: "Камера" }}
  axes={[{ name: "Pitch", minNum: -90, maxNum: 90 }, { name: "Yaw" }, { name: "" }]}
  bind:value={pos}
  onUpdate={(v) => send(v)}
/>
```

## Панель свойств (JoystickProps.svelte)

В конструкторе задают оси и их пределы, иконку центральной кнопки, режим «только чтение» и событие отправки.
