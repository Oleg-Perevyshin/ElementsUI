# 🧭 WidgetAHRS

Настройка фильтра ориентации. Сверху видно, как устройство стоит сейчас: авиагоризонт и углы. Ниже выбирается алгоритм, и под ним только его параметры, без лишних полей других алгоритмов.

## ✨ Что умеет

- 🌅 Рисует авиагоризонт: небо и земля наклоняются по крену и тангажу.
- 🔢 Крупно показывает крен, тангаж и рыскание.
- 🎯 Показывает ноль гироскопа, который фильтр вычитает сам.
- 📉 У ESKF показывает, насколько фильтр не уверен в углах.
- 🔀 Переключает алгоритм: VQF, ESKF, Махони, Маджвик.
- 🧹 Показывает параметры только выбранного алгоритма. Параметры других алгоритмов не видны и не отправляются.
- 🧲 Включает и выключает поправку курса по магнитометру.
- 💾 Правки копятся до кнопки «Сохранить» и уходят одним пакетом.
- 🔽 Сворачивается по клику на заголовок.
- ❓ Кнопка «?» в шапке включает подсказки к каждому полю.

## 🧩 Как настроить в конструкторе

1. Перетащите виджет на макет. Привязывать переменные не нужно.
2. Если нужно, задайте заголовок. Без него карточка называется «Фильтр ориентации» на языке пользователя.
3. Если в прошивке у фильтра другая группа настроек, впишите её. По умолчанию это `AHRF`.
4. Выберите мастер-цвет виджета.

## 💡 Полезно знать

- 🥇 VQF - лучший выбор по умолчанию. ESKF даёт оценку ошибки, Махони и Маджвик самые простые и быстрые.
- 🧲 Без поправки по магнитометру курс считается только по гироскопу от положения при калибровке. У подвеса это значит, что курс следует за рукояткой.
- 🔄 Пока есть несохранённые правки, новые значения настроек с устройства их не затирают. Углы при этом идут как обычно.
- 🆕 Если прошивка сообщит алгоритм, которого виджет не знает, он покажет только выбор алгоритма и углы.
- 📐 Виджет занимает всю ширину своей ячейки, а высота подстраивается под содержимое.

<details>
<summary>📦 Данные устройства</summary>

- Работает с полями группы `AHRF` компонента `ahrs_gimbal` прошивок ProdFactory. Группу можно сменить префиксом в настройках.
- Углы, ноль гироскопа и ошибка оценки только читаются. Обычно они приходят потоком `OK! SystemDataStream`.
- По «Сохранить» уходит один `SET ModuleConfig`: `Mode`, `MU` и параметры выбранного алгоритма. Параметры других алгоритмов не отправляются.
- Какие параметры у какого алгоритма и их диапазоны - таблицы `AHRS_ALGORITHMS` и `AHRS_PARAM_RANGES` в `ahrs.ts`. Новый алгоритм прошивки добавляется туда одной строкой.

<details>
<summary>🔑 Ключи</summary>

| Ключ             | Описание                                                | Алгоритмы             |
| ---------------- | ------------------------------------------------------- | --------------------- |
| `Mode`           | `0` VQF, `1` ESKF, `2` Махони, `3` Маджвик              | все                   |
| `MU`             | `1` - магнитометр поправляет курс                       | все                   |
| `TA`             | Постоянная времени поправки наклона, с, 0.1-30          | VQF                   |
| `TM`             | Постоянная времени поправки курса, с, 0.1-120           | VQF                   |
| `GN`             | Шум гироскопа, °/с/√Гц, 0.0001-1                        | ESKF                  |
| `GB`             | Уход нуля гироскопа, °/с/√с, 0.00001-1                  | ESKF                  |
| `AN`             | Шум акселерометра, g, 0.001-1                           | ESKF, Махони, Маджвик |
| `AG`             | Порог отклонения модуля ускорения от 1 g, 0.01-2        | ESKF, Махони, Маджвик |
| `MN`             | Шум курса по магнитометру, °, 0.1-180                   | ESKF                  |
| `KP`             | Пропорциональный коэффициент, рад/с на рад, 0-10        | Махони                |
| `KI`             | Интегральный коэффициент, 0-1                           | Махони                |
| `KB`             | Шаг по тяжести, рад/с, 0-1                              | Маджвик               |
| `KM`             | Доля ошибки курса на одну поправку по магнитометру, 0-1 | Махони, Маджвик       |
| `R`, `P`, `Y`    | Крен, тангаж, рыскание 0-360°, только чтение            | все                   |
| `BX`, `BY`, `BZ` | Ноль гироскопа, °/с, только чтение                      | все                   |
| `SR`, `SP`, `SY` | Ошибка оценки углов (1 сигма), °, только чтение         | ESKF                  |

</details>
