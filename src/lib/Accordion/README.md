# Accordion

Сворачиваемый блок. В нём группируют компоненты, которые нужны не всегда: настройки, диагностику, редкие разделы.

## Назначение

Сворачиваемый блок для группировки компонентов.

## Пакет данных

С устройством не связан, ничего не читает и не отправляет.

## Особенности

- В конструкторе компоненты перетаскивают внутрь аккордеона. У него своя сетка, её размер задаётся при создании и меняется растягиванием.
- Заголовок с иконкой открывает и закрывает содержимое.
- Мастер-цвет работает как у смарт-виджетов: иконка, текст и стрелка заголовка окрашены цветом из палитры, фон заголовка его мягким оттенком. Без цвета используется акцент темы. Цвет из `label.class` перекрывает цвет текста.
- Закрытый аккордеон занимает одну строку сетки, открытый растягивается по содержимому.
- Содержимое рисуется, только когда аккордеон открыт.
- С картинкой фона (`image`) строки сетки не ниже `6.5rem`.

## Пропсы

| Название | Тип | По умолчанию | Описание |
|---|---|---|---|
| `id` | `string` | `crypto.randomUUID()` | Идентификатор |
| `isOpen` | `boolean` | `false` | Открыт ли. Можно связать через `bind:isOpen` |
| `wrapperClass` | `string` | `""` | Классы обёртки |
| `componentClass` | `string` | `""` | Мастер-цвет: `bg-red`, `bg-green` и другие из `COLOR_OPTIONS`. Пусто — акцент темы |
| `size` | `{ width, height }` | `1 × 1` | Сетка содержимого: колонки и строки |
| `label.name` | `string` | `""` | Заголовок |
| `label.class` | `string` | `"text-left"` | Классы текста заголовка |
| `label.icon` | `Component \| string \| null` | `null` | Иконка заголовка |
| `image` | `string` | `""` | Картинка фона содержимого |
| `children` | `Snippet` | | Содержимое |

Колбэков нет. Открытие и закрытие компонент обрабатывает сам.

## Пример

```svelte
<script>
  import * as UI from "poe-svelte-ui-lib"
  let open = $state(false)
</script>

<UI.Accordion label={{ name: "Сеть" }} componentClass="bg-blue" bind:isOpen={open}>
  <UI.Input label={{ name: "SSID" }} />
</UI.Accordion>
```

## Панель свойств (AccordionProps.svelte)

В конструкторе задают заголовок, иконку, мастер-цвет, картинку фона и размер сетки.
