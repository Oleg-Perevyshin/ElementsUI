# ↔️ Splitter

Разделитель на краю панели: потяните его мышью, и панель станет шире или уже.

## ✨ Что умеет

- 🖱️ Меняет ширину панели перетаскиванием.
- 🎯 Двойной клик возвращает ширину по умолчанию.
- ⌨️ С фокуса двигается стрелками клавиатуры.
- 📏 Ширина в пикселях или в процентах ширины контейнера.
- 🚧 Не пускает ширину за пределы `min` и `max`.

## 💡 Полезно знать

- 🔌 С устройством не связан, в конструкторе его нет: он для раскладки страниц приложений, например список команд и GUI во вкладке DevTerminal и на странице Отладка в DevCloud.
- 💾 Запоминать ширину между запусками должно приложение: разделитель только меняет `value`.
- 👀 Линия видна при наведении и фокусе, во время перетаскивания она цвета акцента.

<details>
<summary>⚙️ Пропсы</summary>

| Название         | Тип                 | По умолчанию | Описание                                                                                                                                |
| ---------------- | ------------------- | ------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| `value`          | `number`            |              | Ширина панели, `bind:value`                                                                                                             |
| `defaultValue`   | `number`            |              | Ширина по двойному клику                                                                                                                |
| `min`, `max`     | `number`            |              | Пределы ширины                                                                                                                          |
| `side`           | `"left" \| "right"` |              | Край панели, где стоит разделитель: `right` - тянуть вправо шире, `left` - тянуть влево шире                                            |
| `unit`           | `"px" \| "%"`       | `"px"`       | Единицы `value`                                                                                                                         |
| `containerWidth` | `number`            | `0`          | Ширина контейнера в px, нужна для `unit="%"`                                                                                            |
| `label`          | `string`            |              | Подсказка при наведении и подпись для экранного диктора                                                                                 |
| `wrapperClass`   | `string`            | `""`         | Классы полосы. По умолчанию её середина на краю панели, при зазоре между панелями её сдвигают в середину зазора: `-right-2` при `gap-2` |

Колбэков нет, ширина приходит через `bind:value`.

</details>

<details>
<summary>🔬 Как устроено</summary>

- Полоса шириной 8 px стоит поверх края панели (`absolute`), поэтому родитель панели должен быть `relative`. Если панели разделены зазором, полосу сдвигают `wrapperClass` в середину зазора, чтобы линия не легла на рамку панели.
- Перетаскивание через `pointer capture`: курсор можно увести за пределы полосы.
- Шаг стрелок - 16 px или 2 %. Значение округляется до десятых.
- Роль `separator` с `aria-valuenow`, `aria-valuemin`, `aria-valuemax`.

</details>

<details>
<summary>💻 Примеры кода</summary>

```svelte
<script>
  import * as UI from "poe-svelte-ui-lib"
  let width = $state(240)
</script>

<div class="relative shrink-0" style="width: {width}px">
  <UI.Splitter bind:value={width} defaultValue={240} min={180} max={640} side="right" label="Ширина списка: тяните, двойной клик - по умолчанию" />
  ...
</div>
```

</details>
