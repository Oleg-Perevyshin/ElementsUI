# 🧭 WidgetEncoder

Энкодер угла: угол, скорость и ноль крупными надписями, флаги чипа, установка нуля и автокалибровка. Энкодер - отдельное устройство с любым применением: обратная связь моторов (бесколлекторных, коллекторных, шаговых), положение осей и ручек, счёт оборотов. Виджет подходит к любому энкодеру, у которого в прошивке тот же договор ключей.

## ✨ Что умеет

- 📐 Показывает угол вала, °, скорость, об/мин, и положение нуля, °.
- 🚦 Показывает режим датчика: стоп, измеряет, автокалибровка или установка нуля.
- 🎯 Кнопка «Ноль здесь» делает текущее положение вала нулём, ноль сохраняется в настройках устройства.
- 🔄 Кнопка «Калибровать» запускает автокалибровку чипа: устройство само вращает вал, полоса времени показывает ход. Перед запуском виджет спрашивает подтверждение: вал должен вращаться свободно.
- ⏳ Пока идёт калибровка, показывает полосу времени и раз в секунду перечитывает настройки датчика: как только прошивка закончила, показывает итог и скорость вала, на которой шла калибровка.
- ⚠️ Показывает флаги чипа: высокая скорость, слабое поле, низкое питание, и итог последней автокалибровки.
- ⚙️ Если выбрана микросхема, показывает раздел «Настройки датчика»: режим работы, направление, частота опроса, полоса, гистерезис, сглаживание скорости. Сохраняются кнопкой «Сохранить», «По умолчанию» ставит заводские настройки чипа.
- 🔽 Сворачивается по клику на заголовок.
- ❓ Кнопка «?» в шапке включает подсказки.

## 🧩 Как настроить в конструкторе

1. Перетащите виджет на макет. Привязывать переменные не нужно.
2. Если нужно, задайте заголовок. Без него карточка называется «Энкодер» на языке пользователя.
3. Если в прошивке у энкодера другая группа настроек, впишите её. По умолчанию это `ENC`.
4. Выберите микросхему, например MT6835. Без неё виджет показывает только показания, ноль и калибровку.
5. Выберите мастер-цвет виджета.

## 💡 Полезно знать

- 🔁 Автокалибровка MT6835 идёт около 30 секунд: устройство вращает вал с постоянной скоростью, вал должен вращаться свободно. Поправки записываются в память чипа, после успеха нужно выключить и включить питание модуля.
- 🔒 «Ноль здесь» и «Калибровать» доступны, только пока датчик измеряет. Пока идёт калибровка или установка нуля, настройки недоступны.
- 🧲 «Слабое поле» - магнит далеко от чипа или сместился, угол будет неточным.
- 🧮 Сглаживание скорости подписано постоянной времени при текущей частоте опроса. Если скорость идёт в контур регулятора, его лучше выключить: задержка раскачивает контур.
- 🧩 Новая микросхема - новая запись `SENSOR_CHIPS` с частью `enc` в `sensorChips.ts`, биты ровно как в структуре `Cfg` драйвера прошивки.
- 📐 Виджет занимает всю ширину своей ячейки, а высота подстраивается под содержимое.

<details>
<summary>📦 Договор с прошивкой</summary>

- Работает с полями группы `ENC`. Группу можно сменить префиксом в настройках.
- Режим датчика - биты 0-1 слова `Cfg`: `0` стоп, `1` измерять, `2` автокалибровка, `3` ноль здесь. Ноль - биты 15-26, шаг 360/4096°.
- «Калибровать» отправляет `SET ModuleConfig {ENC.Cfg: слово}` с `2` в битах 0-1, «Ноль здесь» - с `3`, остальные биты как были.
- Пока идёт калибровка, виджет раз в секунду зовёт `onRefresh`, и приложение шлёт `GET ModuleConfig {CfgGroup: ENC}`: прошивка сама возвращается в режим `1`, но `Cfg` и `CS` без запроса не присылает. Калибровка кончилась, когда драйвер ответил режимом калибровки и вышел из него. `calibrateMs` (по умолчанию 60000 мс) - предел ожидания, если ответа нет, потом виджет перечитывает группу ещё раз. После нуля группа перечитывается через 0.8 с.
- Показания только читаются. Обычно они приходят потоком `OK! SystemDataStream`.

</details>

<details>
<summary>🔑 Ключи</summary>

| Ключ  | Описание                                                                            |
| ----- | ----------------------------------------------------------------------------------- |
| `Cfg` | Биты 0-1 - режим, биты 15-26 - ноль, остальные - настройки микросхемы               |
| `A`   | Угол, °                                                                             |
| `Vel` | Скорость, рад/с                                                                     |
| `ST`  | Флаги чипа: бит 0 высокая скорость, бит 1 слабое поле, бит 2 низкое питание         |
| `CS`  | Итог автокалибровки: `0` не было, `1` идёт, `2` ошибка, `3` успешно                 |
| `CR`  | Скорость вала при последней автокалибровке по замеру датчика, об/мин; `0` - не было |

</details>
