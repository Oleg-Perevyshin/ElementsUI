# Input

Поле ввода. Показывает значение переменной устройства и меняет его: имя устройства, пароль, порог срабатывания.

## Назначение

Показывает и изменяет значение переменной устройства.

## Пакет данных

- Читает одну переменную, например `CFG.DevName`, и показывает её значение.
- Значение отправляется при каждом изменении. Для текста удобнее аргумент `NoSend` и отдельная кнопка «Сохранить».
- Отправка настраивается в событии: **Заголовок** (обычно `SET`) и **Аргумент** (обычно `ModCfg`). С `NoSend` значение сразу не уходит, его отправит другой компонент, например кнопка.

## Ключи

| Ключ | Описание |
|---|---|
| `<переменная>` | Строка или число по типу поля. Для битового поля целое число, меняются только биты с N по M |

## Особенности

Типы поля (`type`):

| Тип | Что это |
|---|---|
| `text` | Обычный текст |
| `password` | Скрытый ввод с кнопкой «показать». Копирование недоступно |
| `number` | Число со стрелками. Точку ввести нельзя, шаг задаёт `number.step` |
| `text-area` | Многострочный текст, высота в строках `textareaRows` |
| `bitMode` | Число для части 32-битного слова. Предел задайте через `number.maxNum` |

- Неверный ввод (длина, диапазон, регулярное выражение `help.regExp`) подсвечивается, под полем появляется текст ошибки, и значение не отправляется.
- Числа округляются до 5 знаков после запятой, чтобы не было хвостов вида `0.30000000000000004`.
- `readonly` превращает поле в отображение значения. Вместе с `help.copyButton` у него появляется кнопка копирования.
- Подсказка `help.info` показывает только текст, без разметки.
- `range` нужен только панели свойств. По нему она считает предел битового поля: `2^(end - start + 1) - 1`. Сам `Input` этот проп не читает.

## Пропсы

| Название | Тип | По умолчанию | Описание |
|---|---|---|---|
| `id` | `string` | `crypto.randomUUID()` | Идентификатор |
| `type` | `"text" \| "password" \| "number" \| "text-area" \| "bitMode"` | `"text"` | Тип поля |
| `value` | `string \| number` | | Значение. Можно связать через `bind:value` |
| `label.name`, `label.class` | `string` | `""` | Заголовок и его классы |
| `wrapperClass`, `componentClass` | `string` | `""` | Классы обёртки и поля |
| `placeholder` | `string` | `""` | Подсказка в пустом поле |
| `disabled` | `boolean` | `false` | Неактивно |
| `readonly` | `boolean` | `false` | Только показ |
| `maxlength` | `number` | `100` | Наибольшая длина текста |
| `textareaRows` | `number` | `3` | Строк у `text-area` |
| `number.minNum`, `number.maxNum` | `number` | `-1000000`, `1000000` | Пределы числа |
| `number.step` | `number` | `1` | Шаг стрелок |
| `range` | `{ start, end }` | | Биты битового поля, только для панели свойств |
| `isValid` | `boolean` | `true` | Значение верное. Компонент ставит его сам по проверкам |
| `help.info` | `string` | `""` | Подсказка у заголовка |
| `help.copyButton` | `boolean` | `false` | Кнопка копирования |
| `help.regExp` | `string \| RegExp` | | Проверка ввода. Готовые выражения на вкладке «Регулярные выражения» витрины |
| `help.autocomplete` | `string \| null` | `"off"` | Атрибут `autocomplete` браузера: `username`, `new-password`, `email` и другие |
| `onUpdate` | `(value) => void` | | Значение изменилось и прошло проверку |

## Примеры

```svelte
<script>
  import * as UI from "poe-svelte-ui-lib"
  let name = $state("")
  let limit = $state(10)
</script>

<UI.Input label={{ name: "Имя устройства" }} bind:value={name} maxlength={31} help={{ regExp: "^[A-Za-z0-9_-]*$" }} />

<UI.Input label={{ name: "Порог, Вт" }} type="number" bind:value={limit} number={{ minNum: 0, maxNum: 3000, step: 10 }} />

<UI.Input label={{ name: "Серийный номер" }} value="10.10.001-01_..." readonly help={{ copyButton: true }} />
```

## Панель свойств (InputProps.svelte)

В конструкторе задают тип поля, заголовок, подсказку, ограничения длины и диапазона, регулярное выражение, режим «только чтение» и событие отправки. Для битового поля задают биты `range`, и панель сама считает предел.
