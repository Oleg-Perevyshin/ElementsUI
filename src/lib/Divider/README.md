# Divider

Разделитель между группами компонентов: линия или пустой отступ.

## Назначение

Визуально разделяет группы компонентов.

## Пакет данных

С устройством не связан.

## Особенности

- Линия всегда во всю ширину. Толщину задаёт `width`.
- Компонент занимает всю высоту, отведённую ему в сетке. Нужный зазор получают, меняя высоту самого разделителя, а `anchor` ставит линию сверху, посередине или снизу.
- Без цвета линия нейтральная (`--hairline-color`). С классом `bg-*` она окрашивается этим цветом.
- В превью интерфейса разделитель всегда получает явную высоту по сетке. Иначе пустая ячейка схлопнулась бы почти в ноль.

## Пропсы

| Название | Тип | По умолчанию | Описание |
|---|---|---|---|
| `id` | `string` | `crypto.randomUUID()` | Идентификатор |
| `wrapperClass` | `string` | `""` | Классы обёртки |
| `type` | `"line" \| "empty"` | `"line"` | Линия или пустой отступ |
| `width` | `number` | `1` | Толщина линии, пикселей |
| `color` | `string` | `""` | Цвет: `bg-max`, `bg-red`, `bg-yellow`, `bg-green`, `bg-blue`, `bg-purple`, `bg-gray`. Пусто — нейтральный |
| `anchor` | `"top" \| "center" \| "bottom"` | `"center"` | Где стоит линия по высоте |

Колбэков нет.

## Пример

```svelte
<UI.Divider />
<UI.Divider color="bg-blue" width={2} anchor="bottom" />
<UI.Divider type="empty" />
```

## Панель свойств (DividerProps.svelte)

В конструкторе задают тип, толщину, цвет и положение линии.
