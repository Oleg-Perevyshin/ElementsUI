# WidgetRGBStrip Component

## Назначение

Управление адресной лентой: цвет, эффект, скорость и параметры самой ленты.

> **Размеры.** Ширина — 100% контейнера (в конструкторе — ширина ячейки сетки), без собственного ограничения; высота — по содержимому, в сетке конструктора виджет занимает одну строку. Мастер-цвет (`componentClass`) перекрашивает весь виджет.

## Пакет данных

- Поля группы `LST` драйвера `RGB_Strip` (меняется префиксом в настройках), привязывать переменные не нужно
- Цвет, эффект и скорость отправляются сразу
- Блок «Оборудование» редактируется локально и уходит одним пакетом по «Сохранить» — лента перезапускается

### Протокол устройства

```
"LST.Color": [255, 120, 0, 0],   // R, G, B, W
"LST.Effect": 0,                 // 0 статичный, 1 радуга, 2 дыхание, 3 палитра, 4 комета, 5 мерцание, 6 огонь, 7 бегущие огни
"LST.Speed": 3,                  // 0..10, 0 — пауза
"LST.Count": 64,                 // 1..MaxCount
"LST.Model": 0,                  // 0 WS2812, 1 SK6812 (RGBW), 2 WS2811
"LST.Order": 0,                  // 0 GRB, 1 RGB, 2 BRG, 3 RBG, 4 GBR, 5 BGR
"LST.MaxCount": 64               // ёмкость из прошивки, только чтение
```

Изменения — `SET ModCfg` с нужными ключами группы. Пин данных и способ передачи (RMT/SPI) задаются
в прошивке (`RGB_Strip_Init`) и через виджет не меняются.

## Ключи

| Ключ       | Описание                                                                                                          |
| ---------- | ----------------------------------------------------------------------------------------------------------------- |
| `Color`    | массив `[R, G, B, W]`, 0–255; `W` только у SK6812                                                                 |
| `Effect`   | число: `0` статичный, `1` радуга, `2` дыхание, `3` палитра, `4` комета, `5` мерцание, `6` огонь, `7` бегущие огни |
| `Speed`    | число 0–10 по нелинейной шкале, `0` — пауза                                                                       |
| `Count`    | число светодиодов, 1–`MaxCount`                                                                                   |
| `Model`    | число: `0` WS2812, `1` SK6812 (RGBW), `2` WS2811                                                                  |
| `Order`    | порядок цветов: `0` GRB, `1` RGB, `2` BRG, `3` RBG, `4` GBR, `5` BGR                                              |
| `MaxCount` | число: ёмкость из прошивки, только чтение                                                                         |

## Особенности

Смарт-виджет адресной светодиодной ленты. Работает с полями группы `LST` ровно в том виде, в каком их
отдаёт драйвер `RGB_Strip` (ProdFactory-ESP). Компонент ничего не знает про DeviceStore/WebSocket —
только `value` и колбэки `onChange`/`onSave`.

- **Свечение** — палитра цвета, белый канал (только для модели SK6812), эффект и скорость. Каждое
  изменение сразу уходит в `onChange`.
- **Оборудование** — количество светодиодов (1…`MaxCount`), модель чипа и порядок цветов.
  Редактируются локально и отправляются одним пакетом по «Сохранить»: прошивка пересоздаёт драйвер
  ленты. Пока правок нет, поля показывают свежие значения с устройства.
- В шапке — образец текущего цвета.

## Пропсы

| Название         | Тип                                                      | По умолчанию                     | Описание                                                                |
| ---------------- | -------------------------------------------------------- | -------------------------------- | ----------------------------------------------------------------------- |
| `id`             | `string`                                                 | `undefined`                      | Префикс группы ленты (`"LST"`), используется вызывающим кодом           |
| `wrapperClass`   | `string`                                                 | `""`                             | CSS-классы обёртки                                                      |
| `componentClass` | `string`                                                 | `""`                             | «Мастер-цвет» виджета — роль вида `"bg-red"`, перекрашивает весь виджет |
| `label`          | `{ name?: string }`                                      | `{ name: "Светодиодная лента" }` | Заголовок карточки                                                      |
| `value`          | `Partial<IWidgetRGBStripConfig>`                         | `undefined`                      | Поля группы `LST`                                                       |
| `keys`           | `Partial<Record<keyof IWidgetRGBStripConfig, string>>`   | `undefined`                      | Переопределение имён полей устройства                                   |
| `collapsed`      | `boolean`                                                | `false`                          | Свёрнуто ли тело виджета (`$bindable`)                                  |
| `persistKey`     | `string`                                                 | `undefined`                      | Ключ для сохранения `collapsed` в `localStorage`                        |
| `onChange`       | `(field: "Color" \| "Effect" \| "Speed", value) => void` | `undefined`                      | Изменение свечения — отправляется сразу; без обработчика только чтение  |
| `onSave`         | `(hardware: { Count, Model, Order }) => void`            | `undefined`                      | Сохранение оборудования одним пакетом                                   |

## Примеры

```svelte
<UI.WidgetRGBStrip
  value={strip}
  onChange={(field, value) => send({ [`LST.${field}`]: value })}
  onSave={(hw) => send({ "LST.Count": hw.Count, "LST.Model": hw.Model, "LST.Order": hw.Order })}
/>
```

## Конструктор свойств (WidgetRGBStripProps.svelte)

Группа «Общие»: заголовок, префикс группы ленты (ID), мастер-цвет.

### Что настраивается

- Префикс группы (ID), мастер-цвет
