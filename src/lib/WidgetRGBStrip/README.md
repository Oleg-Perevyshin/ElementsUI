# WidgetRGBStrip

Смарт-виджет адресной светодиодной ленты: цвет, эффект, скорость эффекта и параметры самой ленты. Работает с драйвером `RGB_Strip` прошивки ProdFactory-ESP.

## Назначение

Управление адресной лентой: цвет, эффект, скорость и параметры ленты.

Ширина виджета равна ширине контейнера, высота по содержимому. В сетке конструктора он занимает одну строку.

## Пакет данных

- Работает с полями группы `LST` драйвера `RGB_Strip`. Группу можно сменить префиксом в настройках.
- Цвет, эффект и скорость отправляются сразу.
- Блок «Оборудование» правится на месте и уходит одним пакетом по «Сохранить». Прошивка после этого перезапускает ленту.

## Ключи

| Ключ | Описание |
|---|---|
| `Color` | `[R, G, B, W]`, каждое 0-255. `W` только у SK6812 |
| `Effect` | `0` статичный, `1` радуга, `2` дыхание, `3` палитра, `4` комета, `5` мерцание, `6` огонь, `7` бегущие огни |
| `Speed` | 0-10 по нелинейной шкале, `0` пауза |
| `Count` | Сколько светодиодов, от 1 до `MaxCount` |
| `Model` | `0` WS2812, `1` SK6812 (RGBW), `2` WS2811 |
| `Order` | Порядок цветов: `0` GRB, `1` RGB, `2` BRG, `3` RBG, `4` GBR, `5` BGR |
| `MaxCount` | Наибольшее число светодиодов, задано в прошивке, только чтение |

## Протокол устройства

```
"LST.Color": [255, 120, 0, 0],
"LST.Effect": 0,
"LST.Speed": 3,
"LST.Count": 64,
"LST.Model": 0,
"LST.Order": 0,
"LST.MaxCount": 64
```

Изменения отправляются `SET ModCfg` с нужными ключами группы. Пин данных и способ передачи (RMT или SPI) задаются в прошивке (`RGB_Strip_Init`), через виджет их не поменять.

## Особенности

- **Свечение.** Палитра цвета, белый канал (только для SK6812), эффект и скорость. Каждое изменение сразу уходит в `onChange`.
- **Оборудование.** Число светодиодов, модель чипа и порядок цветов. Пока правок нет, поля показывают свежие значения с устройства.
- В шапке образец цвета первого светодиода (`Color`), без учёта яркости. Выбранный цвет показывается сразу, ещё до ответа устройства. Эффекты «радуга», «палитра» и «огонь» цвет пикселей не сообщают, поэтому образец остаётся базовым `Color`.
- Без `onChange` виджет только показывает значения.
- Сворачивание, мастер-цвет и кнопка «?» с подсказками работают как у `WidgetWiFi`.

## Пропсы

| Название | Тип | По умолчанию | Описание |
|---|---|---|---|
| `id` | `string` | `"LST"` | Префикс группы |
| `keys` | `Partial<Record<ключ, string>>` | имена ключей | Другие имена полей |
| `value` | `Partial<IWidgetRGBStripConfig>` | | Поля группы |
| `label.name` | `string` | | Заголовок. Пусто - «RGB лента» на языке пользователя |
| `wrapperClass` | `string` | `""` | Классы обёртки |
| `componentClass` | `string` | `""` | Мастер-цвет `bg-*` |
| `collapsed` | `boolean` | `false` | Свёрнут ли |
| `persistKey` | `string` | | Ключ для запоминания свёрнутого состояния |
| `onChange` | `(field: "Color" \| "Effect" \| "Speed", value) => void` | | Изменилось свечение |
| `onSave` | `({ Count, Model, Order }) => void` | | Нажата «Сохранить» в блоке оборудования |

## Пример

```svelte
<UI.WidgetRGBStrip
  value={strip}
  onChange={(field, value) => sendModCfg({ [`LST.${field}`]: value })}
  onSave={(hw) => sendModCfg({ "LST.Count": hw.Count, "LST.Model": hw.Model, "LST.Order": hw.Order })}
/>
```

## Панель свойств (WidgetRGBStripProps.svelte)

В конструкторе задают заголовок, префикс группы ленты и мастер-цвет.
