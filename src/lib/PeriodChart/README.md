# PeriodChart

Столбики накопленных значений с переключателем периода: час, сутки, месяц, год. Например, расход электроэнергии.

## Назначение

Столбики накопленных значений с переключателем периода.

## Пакет данных

- Каждый **уровень** это своя вкладка переключателя и своя переменная устройства.
- Сама диаграмма ничего не запрашивает и не отправляет, данные приходят с устройства.

## Ключи

| Ключ | Описание |
|---|---|
| `<переменная уровня>` | Массив чисел, по столбику на элемент |

## Особенности

- Всегда открывается на первом уровне. Если уровень один, переключателя нет.
- Столбики делят ширину поровну. Ненулевое значение всегда видно, хотя бы на 2% высоты.
- Слева шкала с делениями и сеткой. Она подбирается сама под данные: `0…100`, `0…0.08`, `0…3M`.
- Точное значение видно в подсказке при наведении: 4 значащие цифры и единицы, например `910: 0.0734 мкВт/см²`.
- Подписи под столбиками берутся из `labels` или номера столбика. Если столбиков много, подписи прореживаются, их не больше 12.
- Отрицательные значения не показываются, шкала начинается с нуля.
- Компонент сделан на HTML и CSS без canvas. Он хорош для десятков столбиков. Для сотен и тысяч точек берите `Graph`.
- Округление только для показа, данные в `levels` не меняются.

## Пропсы

| Название | Тип | По умолчанию | Описание |
|---|---|---|---|
| `id` | `string` | `crypto.randomUUID()` | Идентификатор |
| `wrapperClass` | `string` | `""` | Классы обёртки. `bg-*` задаёт цвет переключателя и столбиков |
| `label` | `{ name, class }` | | Заголовок над графиком |
| `levels` | `{ name, variable?, data, labels? }[]` | 4 демо-уровня | Уровни в порядке вкладок |
| `levels[].name` | `string` | | Подпись вкладки, например «Час» |
| `levels[].variable` | `string` | | Переменная устройства, например `PWR.EHour`. Нужна конструктору для подписки, сам компонент её не читает |
| `levels[].data` | `number[]` | | Значения, по столбику на элемент |
| `levels[].labels` | `string[]` | | Подписи столбиков |
| `unit` | `string` | `""` | Единицы для подсказки, например `" Вт·ч"` |
| `onLevelChange` | `(index, level) => void` | | Выбран другой уровень. Здесь можно догрузить данные |

## Пример

```svelte
<UI.PeriodChart
  label={{ name: "Энергия" }}
  unit=" кВт·ч"
  levels={[
    { name: "Сутки", variable: "PWR.EDay", data: [1.2, 0.9, 1.4] },
    { name: "Месяц", variable: "PWR.EMonth", data: [31, 28, 35] },
  ]}
/>
```

## Панель свойств (PeriodChartProps.svelte)

В конструкторе задают уровни (подпись и переменную каждого), единицы и цвет.
