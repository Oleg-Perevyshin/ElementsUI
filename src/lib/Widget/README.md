# Widget

Карточка одного значения: крупная цифра, иконка и управление. Например, скорость вентилятора с кнопками ± или уставка температуры со слайдером.

## Назначение

Карточка одного значения: крупная цифра, иконка и управление.

## Пакет данных

- Читает и пишет одну переменную.
- Изменение отправляется сразу.
- Отправка настраивается в событии: **Заголовок** (обычно `SET`) и **Аргумент** (обычно `ModCfg`). С `NoSend` значение сразу не уходит, его отправит другой компонент.

## Ключи

| Ключ | Описание |
|---|---|
| `<переменная>` | Число в пределах от минимума до максимума |

## Особенности

- Управление бывает трёх видов (`settings.type`): поле с кнопками ± (`input`), слайдер (`slider`) или переключатель (`switch`, значение 0 или 1).
- Набор иконок распределяется по диапазону значения: чем больше значение, тем «дальше» иконка.
- С `icons.cycling` иконки сменяются по кругу, и тем быстрее, чем больше значение. Так анимируется, например, вентилятор. Таймер останавливается при размонтировании.
- Значение не выходит за пределы и округляется до шага.
- `readonly` оставляет только показ.
- Цвет иконки выводится из того же мастер-цвета `bg-*`, что и у карточки.

## Пропсы

| Название | Тип | По умолчанию | Описание |
|---|---|---|---|
| `id` | `string` | `crypto.randomUUID()` | Идентификатор |
| `value` | `number` | `0` | Значение. Для `switch` 0 или 1 |
| `label.name`, `label.class` | `string` | `""` | Заголовок и его классы |
| `wrapperClass` | `string` | | Классы обёртки, здесь же мастер-цвет `bg-*` |
| `readonly` | `boolean` | `false` | Только показ |
| `settings.type` | `"input" \| "switch" \| "slider"` | `"input"` | Вид управления |
| `settings.label` | `string` | `""` | Подпись над управлением |
| `settings.class` | `string` | | Классы блока управления |
| `settings.number.minNum`, `maxNum` | `number` | `0`, `1000` | Пределы |
| `settings.number.step` | `number` | `1` | Шаг |
| `settings.number.units` | `string` | | Единицы рядом со значением |
| `settings.switch.captionLeft`, `captionRight` | `string` | `"Off"`, `"On"` | Подписи переключателя |
| `icons.array` | `string[]` | `[]` | Иконки, SVG-строки |
| `icons.cycling` | `boolean` | `true` | Менять иконки по кругу |
| `icons.class` | `string` | | Классы иконок |
| `onUpdate` | `(value: number) => void` | | Значение изменилось |

## Пример

```svelte
<UI.Widget
  label={{ name: "Вентилятор" }}
  wrapperClass="bg-blue"
  bind:value={fan}
  settings={{ type: "slider", number: { minNum: 0, maxNum: 100, step: 5, units: "%" } }}
  icons={{ array: [IconFan], cycling: true }}
/>
```

## Панель свойств (WidgetProps.svelte)

В конструкторе задают вид управления, пределы, единицы, иконки, анимацию и мастер-цвет.
